# 🗺️ Яндекс Карты

Качество справочника, интегральные метрики и продуктовый ML режима «Идеи».

```dataview
TABLE WITHOUT ID file.link AS "Карточка", priority AS "Приоритет", speaker AS "Лектор"
FROM "Лекции и видео/Разборы лекций/Яндекс Карты"
WHERE file.name != "🏠 Яндекс Карты"
SORT priority ASC, file.name ASC
```
