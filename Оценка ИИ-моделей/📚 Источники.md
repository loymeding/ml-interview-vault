# 📚 Источники — Оценка ИИ-моделей

> [!note] Принцип
> Здесь важны не «самые новые названия моделей», а воспроизводимые подходы к оценке. Для каждой карточки сначала разберитесь в механизме и ограничениях, затем переходите к конкретным фреймворкам и свежим benchmark’ам.

## Основные книги и статьи

- Ron Kohavi, Diane Tang, Ya Xu — *Trustworthy Online Controlled Experiments* — доверительные эксперименты и решение по метрикам.
- Chip Huyen — *Designing Machine Learning Systems* — production-контур, данные, мониторинг и эксплуатация ML.
- Valerii Babushkin, Arseny Kravchenko — *Machine Learning System Design* — системный каркас ML-кейсов.
- OpenAI — *Evals* documentation — подходы к созданию eval-наборов и проверке моделей.
- Anthropic — материалы по model evaluations и alignment assessments — дизайн задач, safety и capability evaluation.
- Stanford CRFM — HELM — многомерная оценка языковых моделей.
- LMSYS — материалы по pairwise evaluation и arena-style comparisons.
- Papers по AlpacaEval, MT-Bench, Arena-Hard — парное сравнение и judge-модели.
- Papers по G-Eval, JudgeLM и LLM-as-a-Judge — автоматические оценщики и их ограничения.
- Papers по ToolBench, WebArena, OSWorld, SWE-bench, GAIA — benchmark’и для агентных систем.
- Papers по MMMU, MathVista, MMBench, ToolVQA и multi-image evaluation — мультимодальные benchmark’и.

## Источники для прикладного ML System Design

- [ML-интервью Яндекса](https://yandex.ru/jobs/interview/mldev) — формат кейса: постановка задачи, данные, признаки, выбор модели, offline/online-метрики, ranking и uplift.
- [Как пройти собеседование по машинному обучению — Яндекс](https://habr.com/ru/companies/yandex/articles/475584/) — примеры прикладных кейсов и ожидания от кандидата.
- [Rules of Machine Learning — Google](https://developers.google.com/machine-learning/guides/rules-of-ml) — практические правила запуска и сопровождения моделей.
- [CS329S: Machine Learning Systems Design — Stanford](https://web.stanford.edu/class/cs329s/) — системный взгляд на данные, модель и эксплуатацию.
- [RAGAS](https://arxiv.org/abs/2309.15217) — разложение оценки RAG на retrieval и generation аспекты.
- [HELM](https://crfm.stanford.edu/helm/index.html) — многомерная оценка языковых моделей.
- [DocVQA](https://openaccess.thecvf.com/content/WACV2021/papers/Mathew_DocVQA_A_Dataset_for_VQA_on_Document_Images_WACV_2021_paper.pdf), [LayoutLM](https://arxiv.org/abs/1912.13318), [Donut](https://github.com/clovaai/donut) — задачи и подходы для документов.
- [Uplift Modeling: A Review](https://arxiv.org/abs/2308.09066), [CausalML](https://causalml.readthedocs.io/en/stable/), [EconML](https://www.pywhy.org/EconML/index.html) — причинный эффект и uplift.
- [Yandex Handbook: ranking](https://education.yandex.ru/handbook/ml/article/zadacha-ranzhirovaniya) и [введение в рекомендательные системы](https://education.yandex.ru/handbook/ml/article/intro-recsys) — ранжирование и рекомендации.
- [Scoring all: ML в Лавке](https://dev.go.yandex/blog/scoring-all-ml-in-lavka-2025-06-19) — продуктовый контекст ML-сценариев в Яндексе.
- [Yandex GPT Week](https://shad.yandex.ru/gptweek) — устройство LLM: данные, предобучение, alignment и inference.
- [Alice AI и агентные сценарии](https://yandex.ru/company/news/28-10-2025-01) — контекст Алисы, файлов, изображений и многошагового поиска.
