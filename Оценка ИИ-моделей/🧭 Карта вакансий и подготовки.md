# Карта вакансий и подготовки

## Общий вывод

Во всех вакансиях основной предмет работы — не обучение нейросети «с нуля», а измерение качества, анализ ошибок, создание данных и решение о том, стоит ли новой версии модели попадать к пользователям. Различается объект оценки: обычная LLM, агент, VLM или генератор изображений.

| Направление | Главный объект оценки | Ключевые карточки |
|---|---|---|
| Приёмка Alice AI | Новая версия LLM/VLM и её регрессии | Приёмка, benchmark, статистика, judge, разметка, offline→online, воспроизводимый процесс |
| Alice AI Agents | Многошаговая задача с API сервисов | Агентная оценка, среды, tool use, trajectories, RL-данные |
| YandexART | Генерация/редактирование изображений и визуальный агент | VLM, image evaluation, VLM-feedback loop, judge, данные |
| Аналитика базовой LLM | Ошибки, срезы, данные, краудсорсинг | Таксономия ошибок, разметка, data curation, benchmark |
| Alice AI VLM | Multi-image, reasoning, вызовы инструментов | VLM evaluation, агенты, benchmark, judge, trajectories |
| Широкая команда качества | Разные навыки: речь, перевод, LLM, VLM, файлы | Приёмка, benchmark, разметка, статистика, исследование benchmark’ов |
