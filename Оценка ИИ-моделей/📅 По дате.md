# 📅 По дате — Оценка ИИ-моделей

```dataview
TABLE WITHOUT ID
  file.link as "Карточка",
  создано as "Создано",
  file.mtime as "Изменено",
  готовность as "Готовность"
FROM "Оценка ИИ-моделей"
WHERE статус
SORT file.mtime DESC
```
