## Что должно получаться на интервью

- объяснить не только синтаксис, но и модель выполнения;
- выбрать структуру данных и назвать сложность основных операций;
- написать небольшой production-фрагмент с обработкой ошибок;
- увидеть проблему в чужом коде;
- назвать крайние случаи и предложить тесты;
- связать решение с типом нагрузки: CPU, I/O, память, задержка.

## 📊 Прогресс

```dataview
TABLE WITHOUT ID
  length(rows) as "📚 Заметок",
  length(filter(rows, (r) => r.статус = "готово")) as "✅ Готово",
  length(filter(rows, (r) => r.статус = "черновик")) as "✏️ Черновик",
  length(filter(rows, (r) => r.сложность = "высокая")) as "🔴 Сложных"
FROM "Python"
WHERE статус
  AND file.folder != "Python"
  AND file.folder != "Python/Шаблоны"
GROUP BY true
```

## ⚠️ Требуют внимания

```dataview
TABLE WITHOUT ID file.link as "Заметка", file.folder as "Раздел", статус
FROM "Python"
WHERE (статус = "черновик" OR статус = "требует доработки")
  AND file.folder != "Python"
  AND file.folder != "Python/Шаблоны"
SORT file.folder ASC
```
