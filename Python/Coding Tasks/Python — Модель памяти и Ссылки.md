## T001. Безопасное значение по умолчанию

**Задача:** исправить функцию так, чтобы вызовы не делили один и тот же список.

~~~python
def add_item(item, items=[]):
    items.append(item)
    return items
~~~

Ожидаемое поведение:

~~~python
add_item("a")  # ["a"]
add_item("b")  # ["b"]
~~~

Объясните, когда создаётся значение по умолчанию и почему вариант с None исправляет проблему.
