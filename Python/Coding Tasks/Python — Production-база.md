# Coding Tasks — production-база

Теория: [[Python/Основы/Python — Production-база: исключения, контекстные менеджеры, типизация и тесты|карточка по production-приёмам]]

## T001. Контекстный менеджер для таймера

Напишите `timer(name)`, который измеряет длительность блока, логирует её в `finally` и не подавляет исключения.

~~~python
with timer("feature_build"):
    build_features(rows)
~~~

Обсудите, что должно произойти, если `build_features` завершился ошибкой, и почему запись времени должна выполняться до проброса исключения.

## T002. Безопасный вызов API

Реализуйте функцию, которая делает до трёх попыток вызова `request`, повторяя только `TimeoutError` и `ConnectionError`.

Требования:

- у каждого запроса есть timeout;
- задержка между попытками растёт;
- последняя ошибка пробрасывается наружу;
- вызов с побочным эффектом выполняется только при наличии идемпотентного ключа.

## T003. Граница JSON и бизнес-логика

Опишите ожидаемый payload через `TypedDict`, проверьте обязательные поля и преобразуйте его в `dataclass` `User`.

Обсудите, какие ошибки относятся к ошибкам входных данных, где их обрабатывать и чем unit-тест заменит внешний API.

## T004. Диагностика памяти

Дана функция, которая на каждом вызове добавляет данные в глобальный список. Напишите тест или небольшой диагностический скрипт с `tracemalloc`, подтверждающий рост памяти, и предложите исправление.
