# Python — Итераторы, Генераторы и Списки

> [!abstract] Суть
> Итераторы и генераторы — это инструменты «ленивых» вычислений, позволяющие обрабатывать данные по одному элементу за раз, экономя оперативную память.

## Простыми словами

*   **Итератор** — это как закладка в книге. Вы знаете, на какой странице сейчас находитесь, и можете перелистнуть на следующую, но не обязаны держать в голове всё содержание книги одновременно.
*   **Генератор** — это «фабрика» страниц. Он не печатает всю книгу сразу, а создает следующую страницу только тогда, когда вы его об этом попросите. Это позволяет «читать» бесконечные книги, которые не поместились бы на полке (в оперативной памяти).
*   **Списки** — это готовые переплеты. Все данные уже лежат в памяти, и вы можете мгновенно открыть любую страницу по номеру.

## Ответ

**Формальные определения и протоколы**

1.  **Iterable (Итерируемый объект)**: Объект, у которого определен метод `__iter__`, возвращающий итератор (например, `list`, `str`, `dict`).
2.  **Iterator (Итератор)**: Объект, у которого есть метод `__next__`. При каждом вызове он возвращает следующий элемент или выбрасывает исключение `StopIteration`.
3.  **Generator (Генератор)**: Частный случай итератора, создаваемый с помощью функции с ключевым словом `yield` или генераторного выражения `(x for x in range(10))`. Он автоматически сохраняет состояние выполнения функции между вызовами.

**Списки: Производительность и Память (из файла вопросов)**

*   **Append vs Срезы**: `list.append()` — это эффективная операция добавления в конец ($O(1)$ амортизированно). Срезы (например, `l[len(l):] = [x]`) создают копии частей списка, что делает их медленнее и затратнее по памяти.
*   **Сложность вставки**:
    *   Добавление в конец (append): $O(1)$.
    *   Добавление в начало (insert(0, x)): $O(n)$, так как Python приходится сдвигать все существующие элементы в памяти на одну позицию вправо.
*   **List vs Numpy.array**:
    *   `list` — это массив ссылок на объекты. Объекты могут быть разных типов и разбросаны по всей памяти.
    *   `numpy.array` — это непрерывный блок памяти с данными одного типа. Это позволяет использовать векторные инструкции процессора (SIMD), что в разы ускоряет математические вычисления.

**Итерация по датасету (Pandas)**

При работе с большими таблицами выбор метода итерации критичен:
*   `df.iterrows()`: Возвращает индекс и строку как Series. **Очень медленно**, так как на каждой итерации создается новый объект Series.
*   `df.itertuples()`: Возвращает именованные кортежи. Значительно быстрее iterrows.
*   **Векторизация**: Самый эффективный способ — избегать циклов вовсе, применяя операции ко всему столбцу (`df['col'] * 2`).

## Короткий пример

```python
# Генератор (ленивый)
def my_gen(n):
    for i in range(n):
        yield i ** 2

# Использование
gen = my_gen(1000000) # Память не занята под миллион чисел
print(next(gen)) # 0
print(next(gen)) # 1
```

## Типичные ошибки

*   **Повторная итерация**: Генератор можно обойти только один раз. Если нужно пройтись по данным снова, генератор придется создавать заново.
*   **Преобразование в список**: Написание `list(generator)` убивает всю пользу от ленивых вычислений, так как мгновенно загружает все данные в RAM.

## Каверзные вопросы

> [!question] Что случится, если вызвать next() у итератора, в котором закончились элементы?
> Python выбросит исключение `StopIteration`. Именно так циклы `for` понимают, когда нужно остановиться.

> [!question] Почему добавление в конец списка занимает O(1), если список — это массив?
> Python выделяет память «с запасом» (over-allocation). Если запас есть, вставка мгновенна. Если место закончилось, Python выделяет новый блок памяти побольше, копирует данные и снова оставляет запас.
