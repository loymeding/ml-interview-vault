# Python — Структуры данных: Словари (Dict)

> [!abstract] Суть
> Словарь в Python (`dict`) — это высокооптимизированная хэш-таблица. Она обеспечивает среднюю сложность $O(1)$ для поиска, вставки и удаления элементов. Порядок ключей сохраняется начиная с Python 3.7+ благодаря новой компактной реализации.

## Ответ

### 1. Как устроен dict внутри?
В основе лежит **хэш-таблица** с открытой адресацией для разрешения коллизий.
*   **Хэширование**: Когда вы добавляете ключ, Python вычисляет его `hash()`. Это число определяет индекс в таблице.
*   **Компактное представление (с Python 3.6+)**: Раньше словари занимали много памяти. Теперь используется два массива:
    1.  Плотный массив `entries`, где хранятся сами данные (хэш, ключ, значение) в порядке добавления.
    2.  Разреженная таблица индексов, которая хранит только указатели на позиции в `entries`.
    *Это позволило снизить потребление памяти на 20-25% и автоматически сохранило порядок вставки.*

### 2. Разрешение коллизий
Если два разных ключа имеют одинаковый хэш (или хэш ведет в тот же слот), Python использует **открытую адресацию** (метод проб). Он ищет следующий свободный слот по определенной формуле, пока не найдет пустую ячейку или искомый ключ.

### 3. Сложность операций

| Операция | Средняя сложность | Худшая сложность |
| :--- | :--- | :--- |
| **Поиск** | $O(1)$ | $O(n)$ |
| **Вставка** | $O(1)$ | $O(n)$ |
| **Удаление** | $O(1)$ | $O(n)$ |

*Худший случай $O(n)$ наступает при катастрофическом количестве коллизий (плохая хэш-функция).*

## Короткий пример

```python
# Создание словаря
d = {"a": 1, "b": 2}

# Поиск - O(1)
value = d["a"]

# Добавление - O(1)
d["c"] = 3

# Удаление - O(1)
del d["b"]
```

## Типичные ошибки

*   **Использование изменяемых объектов в качестве ключей:** Ключ словаря должен быть **hashable** (неизменяемым). Список `[1, 2]` не может быть ключом, так как его содержимое может измениться, что сломает хэш-таблицу. Используйте кортеж `(1, 2)`.
*   **Модификация словаря во время итерации:** Вызов `d.pop()` или добавление ключей во время цикла по `d.items()` вызовет `RuntimeError`.

## Каверзные вопросы

> [!question] Почему в Python 3.7+ словари сохраняют порядок добавления ключей?
> Это побочный эффект оптимизации памяти (compact dicts). Данные теперь хранятся в плотном массиве в порядке поступления, а хэш-таблица лишь ссылается на индексы в этом массиве.
