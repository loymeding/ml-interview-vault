# Эволюция GPT: Обучение без учителя как сжатие данных (GPT-1)

> [!abstract] Суть
> GPT-1 заложила основу современных LLM, отказавшись от Энкодера в пользу **Decoder-only** архитектуры. Главный инсайт из теории информации: задача предсказания следующего слова математически эквивалентна задаче **сжатия данных без потерь** (принцип Minimum Description Length). Чтобы идеально предсказывать текст из Википедии, модель обязана выучить не просто грамматику, а фундаментальные законы мира — физику, логику, математику.

## Ответ

### 1. Архитектура Decoder-Only

Авторы OpenAI взяли оригинальный Трансформер и радикально упростили его:
- Полностью убрали **Энкодер** (нет задачи чтения исходного языка)
- Убрали **Cross-Attention** (он соединял Декодер с Энкодером)
- Осталась стопка из 12 блоков: **Masked Multi-Head Self-Attention + Feed Forward**

**Почему односторонняя маска критически важна:** при генерации токена на позиции $i$ модель должна видеть только прошлое ($t_1, \ldots, t_{i-1}$). Без маски через Q, K, V она «подсматривала» бы $t_{i+1}$ во время обучения и вместо выработки способности генерировать — просто выучила бы копирование ответов.

### 2. Предсказание следующего слова = Сжатие данных

Связь из теории информации:
- Лучший компрессор — тот, кто нашёл максимум скрытых паттернов в данных
- Минимизировать неопределённость (энтропию) предсказаний = идеально сжимать текст
- Сжать текст можно, только **глубоко поняв его структуру**

Принцип MDL (Minimum Description Length): лучшее описание набора данных — та модель, которая сжимает их сильнее всего.

### 3. Формирование модели мира (World Model)

Пример: детективная книга из 12 глав. Модель читает 11 глав и середину 12-й: «Убийца — это...». Чтобы предсказать следующее слово (имя убийцы), нельзя опереться на поверхностную статистику — нужно:
- Проанализировать все улики из предыдущих глав
- Выстроить внутреннюю логическую картину мира
- Сделать умозаключение

Таким образом, обучение на огромных текстах принуждает модель выучивать сложные абстрактные концепты.

### 4. Mechanistic Interpretability: механизм «копирования»

Исследователи обнаружили, что внутри Трансформеров формируются понятные подпрограммы (circuits). Например, **механизм «копирования»**: если нужно сгенерировать редкое имя или слово с опечаткой, модель находит его в левом контексте и напрямую копирует — не придумывает заново.

### 5. Пайплайн GPT-1: два этапа обучения

1. **Unsupervised Pre-training:** на гигантском корпусе текстов — максимизация вероятности следующего слова без разметки
2. **Supervised Fine-Tuning:** добавляется линейный слой поверх последнего токена для задач классификации; к loss классификации прибавляют loss языкового моделирования для лучшей сходимости

### 6. Зарождение Zero-Shot

Уже GPT-1 показал: модель, учившаяся предсказывать следующее слово, попутно выучила ставить запятые, делать анализ тональности и переводить тексты — просто потому что это нужно для предсказания. Эти навыки извлекаются без явного обучения.

## Формула / Схема

**Задача предобучения — максимизация правдоподобия:**
$$\Large \mathcal{L}_{\text{LM}} = \sum_{i} \log P(w_i \mid w_{i-k}, \ldots, w_{i-1};\, \Theta)$$

где:
- $w_i$ — предсказываемый токен
- $w_{i-k}, \ldots, w_{i-1}$ — окно контекста длиной $k$
- $\Theta$ — параметры модели (максимизируем по $\Theta$)

**Пайплайн GPT-1:**

$$\text{Корпус (без разметки)} \xrightarrow{\text{Pre-training}} \text{GPT-1} \xrightarrow{+ \text{Linear Layer}} \xrightarrow{\text{Fine-tuning}} \text{Конкретная задача}$$

## Короткий пример

Модель GPT-1 учится на задаче: дан текст «The capital of France is», предсказать «Paris». Неявным образом она при этом выучивает географию, грамматику и логику.

```python
from transformers import GPT2LMHeadModel, GPT2Tokenizer  # GPT-2 доступнее для демо

model = GPT2LMHeadModel.from_pretrained("gpt2")
tokenizer = GPT2Tokenizer.from_pretrained("gpt2")

inputs = tokenizer("The capital of France is", return_tensors="pt")
output = model.generate(**inputs, max_new_tokens=5)
print(tokenizer.decode(output[0]))  # → "The capital of France is Paris"
```

## Типичные ошибки

- **Считать, что языковая модель учит только синтаксис:** чтобы предсказывать текст из Википедии, детективов или научных статей, модель обязана выучить факты, логику, физику, арифметику. Синтаксис — лишь верхушка айсберга.
- **Использовать двунаправленный контекст для авторегрессионной генерации:** обучая GPT, маскированный Attention обязателен. Без маски модель просто «скопирует» правильный ответ при обучении — генерации не произойдёт.

## Каверзные вопросы

> [!question] Почему при долгой генерации (длинный текст на инференсе) качество GPT-моделей падает по сравнению с короткой?
> Причина — **накопление ошибок Teacher Forcing**. При обучении модель всегда видит идеальный текст человека как контекст. На инференсе она опирается на свои же предсказания: если допустила ошибку в начале, следующие шаги строятся на этом «бреде» — ошибки накапливаются снежным комом.
