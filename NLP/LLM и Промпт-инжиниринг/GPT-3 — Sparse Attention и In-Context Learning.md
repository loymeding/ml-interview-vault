# GPT-3: Sparse Attention и In-Context Learning

> [!abstract] Суть
> GPT-3 (175 млрд параметров) — это всё тот же Decoder-only Трансформер, но с двумя ключевыми нововведениями. **Sparse Attention** снизил квадратичную сложность $O(N^2)$ до $O(N\sqrt{N})$, позволив работать с длинными контекстами. А парадигма **In-Context Learning (Few-Shot)** показала: веса модели не нужно обновлять — достаточно добавить несколько примеров задачи прямо в промпт, и замороженная модель решает её не хуже файнтюнингованных специализированных аналогов.

## Ответ

### 1. Масштаб: данные и параметры

- Параметры: 1.5B (GPT-2) → **175B** (×115)
- Batch size: до **3.2M токенов**
- Датасет: отфильтрованный Common Crawl + WebText2 + книги + Wikipedia = **300B токенов**
- Фильтрация качества: классификатор обучен на оценках Reddit — плохие документы удалены

### 2. Проблема классического Attention

**Dense Attention** (GPT-1/2): каждый токен вычисляет скалярное произведение со всеми предыдущими. Сложность $O(N^2)$ по памяти и вычислениям — физически не позволяет обучать на длинных контекстах.

### 3. Sparse Attention (Разреженное внимание)

Матрица внимания разбивается на два паттерна:
- **Local (Локальный):** каждый токен смотрит только на $K$ ближайших соседей слева
- **Strided (Шагающий):** каждый токен смотрит на каждый $M$-й токен из прошлого

Комбинируя паттерны, информация всё равно протекает через всю длину текста через «глобальные узлы-хабы», но матрица разрежена → сложность $O(N\sqrt{N})$.

### 4. Flash Attention: аппаратная альтернатива

Индустрия эволюционировала от алгоритмических аппроксимаций к **аппаратным** оптимизациям.

**Flash Attention** вычисляет математически **точный** Dense Attention, но минимизирует дорогие перемещения данных между медленной видеопамятью (HBM) и быстрым кэшем GPU (SRAM):
- Потребление VRAM: **в 10 раз ниже**
- Результат идентичен классическому Attention (без аппроксимаций)

Именно поэтому Flash Attention стал стандартом, а не Sparse Attention.

### 5. In-Context Learning: Zero, One, Few-Shot

**Zero-Shot:** описание задачи на естественном языке:
> «Переведи на французский: cheese =>»

**One-Shot:** описание + 1 пример правильного решения

**Few-Shot:** описание + ~32 примера

Инсайт: качество кардинально растёт с добавлением примеров. Few-Shot GPT-3 (175B) способен обойти специализированные SOTA-модели, файнтюнингованные на тысячах размеченных примеров.

### 6. Emergent Abilities

Модель научилась:
- Складывать **трёхзначные числа**
- Использовать **выдуманные слова** в правильном контексте: если промпт содержит «блупу — это очень быстрая машина», модель логично продолжает «У нас в гараже стоит блупу»

Это доказывает: модель не зазубрила Википедию, а научилась оперировать **абстрактными концептами** «на лету».

## Формула / Схема

**Сложность внимания:**

| Метод | Сложность |
|-------|-----------|
| Dense Attention | $O(N^2)$ |
| Sparse Attention | $O(N\sqrt{N})$ |
| Flash Attention | $O(N^2)$ (математически), ~10× экономия VRAM |

**Эволюция парадигм обучения:**

| Эпоха | Подход |
|-------|--------|
| GPT-1 / BERT | Pre-training → Fine-Tuning (обновляем веса на тысячах примеров) |
| GPT-3 | Pre-training → In-Context Learning (веса заморожены, ~32 примера в промпте) |

## Типичные ошибки

- **Считать, что Few-Shot обновляет веса модели:** главное концептуальное заблуждение. Во время In-Context Learning никакого градиентного шага нет. Как только сессия заканчивается — знания исчезают.
- **Ожидать SOTA от GPT-3 без примеров:** вся магия раскрывается в Few-Shot. Zero-Shot даёт среднее качество — добавьте 32 примера и результат изменится кардинально.

## Каверзные вопросы

> [!question] Как GPT-3 «понимает», что от неё требуется решить задачу из Few-Shot примеров, а не просто продолжить текст?
> В интернете часто встречается формат: «Пример 1: X → Y. Пример 2: A → B. Пример 3: C → ?». Языковая модель стремится предсказать наиболее вероятное продолжение текста (минимизировать перплексию). Единственным статистически логичным продолжением такого паттерна является применение найденного правила к новому элементу.
