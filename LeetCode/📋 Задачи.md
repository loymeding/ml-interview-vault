# LeetCode Задачи

> Реши задачу -> открой файл -> поставь `статус: решено` в Properties. Таблица обновится сама.
> Детальная аналитика → [[📊 Аналитика]]

## Статистика

```dataview
TABLE WITHOUT ID
  сложность AS "Сложность",
  length(rows) AS "Всего",
  length(filter(rows, (r) => r.статус = "решено")) AS "Решено",
  length(rows) - length(filter(rows, (r) => r.статус = "решено")) AS "Осталось",
  round(length(filter(rows, (r) => r.статус = "решено")) / length(rows) * 100) + "%" AS "%"
FROM "LeetCode/Задачи"
WHERE номер
GROUP BY сложность
SORT сложность ASC
```

## Все задачи

```dataview
TABLE WITHOUT ID
  номер AS "#",
  file.link AS "Задача",
  elink(ссылка, "↗") AS "🔗",
  тип AS "Тип",
  алгоритм AS "Алгоритм",
  сложность AS "LC",
  попытки AS "Попытки",
  дата AS "Дата",
  choice(статус = "решено", "✅", "⬜") AS "✓"
FROM "LeetCode/Задачи"
WHERE номер
SORT номер ASC
```
