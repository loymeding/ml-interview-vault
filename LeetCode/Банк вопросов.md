# Банк вопросов — LeetCode

> Задачи без решения. Открой файл -> поставь `статус: решено`.

## Нерешённые

```dataview
TABLE WITHOUT ID
  номер AS "#",
  file.link AS "Задача",
  elink(ссылка, "↗") AS "↗",
  сложность AS "LC",
  тип AS "Тип"
FROM "LeetCode/Задачи"
WHERE статус = "не решено" AND номер
SORT номер ASC
```
