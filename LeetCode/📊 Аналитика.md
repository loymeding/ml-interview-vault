# 📊 LeetCode — Аналитика

---

## Прогресс по сложности

```dataview
TABLE WITHOUT ID
  сложность AS "Сложность",
  length(rows) AS "Всего",
  length(filter(rows, (r) => r.статус = "решено")) AS "Решено",
  length(rows) - length(filter(rows, (r) => r.статус = "решено")) AS "Осталось",
  round(length(filter(rows, (r) => r.статус = "решено")) / length(rows) * 100) + "%" AS "Прогресс"
FROM "LeetCode/Задачи"
WHERE номер
GROUP BY сложность
SORT сложность ASC
```

## Прогресс по типу алгоритма

```dataview
TABLE WITHOUT ID
  тип AS "Тип",
  length(rows) AS "Всего",
  length(filter(rows, (r) => r.статус = "решено")) AS "Решено",
  length(rows) - length(filter(rows, (r) => r.статус = "решено")) AS "Осталось",
  round(length(filter(rows, (r) => r.статус = "решено")) / length(rows) * 100) + "%" AS "%"
FROM "LeetCode/Задачи"
WHERE номер AND тип
GROUP BY тип
SORT length(filter(rows, (r) => r.статус = "решено")) DESC
```

## На повторение

> Задачи, отмеченные `повторить: true` — пройди ещё раз.

```dataview
TABLE WITHOUT ID
  номер AS "#",
  file.link AS "Задача",
  elink(ссылка, "↗") AS "🔗",
  сложность AS "LC",
  тип AS "Тип",
  дата AS "Дата"
FROM "LeetCode/Задачи"
WHERE повторить = true AND номер
SORT сложность ASC
```

## Нерешённые по типу

> Показывает, каких тем ещё не касался среди нерешённых.

```dataview
TABLE WITHOUT ID
  тип AS "Тип",
  length(rows) AS "Нерешённых"
FROM "LeetCode/Задачи"
WHERE статус = "не решено" AND тип AND номер
GROUP BY тип
SORT length(rows) DESC
```

## Без категории (тип не заполнен)

> Эти задачи стоит разметить, чтобы аналитика по типам была точной.

```dataview
TABLE WITHOUT ID
  номер AS "#",
  file.link AS "Задача",
  сложность AS "LC",
  статус AS "Статус"
FROM "LeetCode/Задачи"
WHERE номер AND (тип = "" OR !тип)
SORT статус ASC, номер ASC
```
