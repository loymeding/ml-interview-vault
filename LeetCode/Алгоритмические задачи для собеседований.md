## 🎮 Как работать с задачей

| Шаг | Действие | Зачем |
|---|---|---|
| <span style="background:#dbeafe;color:#1d4ed8;font-weight:700;padding:3px 8px;border-radius:999px;">1. Открыть</span> | Читать только условие и примеры. | Не подсмотреть паттерн раньше времени. |
| <span style="background:#fef3c7;color:#92400e;font-weight:700;padding:3px 8px;border-radius:999px;">2. Решить</span> | 20-40 минут честной попытки. | Натренировать распознавание задачи. |
| <span style="background:#f3e8ff;color:#6b21a8;font-weight:700;padding:3px 8px;border-radius:999px;">3. Открыть спойлер</span> | Подсказка → идея → решение. | Разобрать именно место затыка. |
| <span style="background:#dcfce7;color:#166534;font-weight:700;padding:3px 8px;border-radius:999px;">4. Обновить статус</span> | `статус`, `попытки`, `дата`, `повторить`. | Чтобы трекер сам показывал прогресс. |

> [!info] 🧭 Где лежат спойлеры
> Классификация из Excel и паттерны вынесены в [[LeetCode/Interview Problems/Метаданные и спойлеры из Excel|Метаданные и спойлеры из Excel]]. В самих карточках они тоже спрятаны в свернутых callout-блоках.

## 📊 Прогресс по источникам

```dataview
TABLE WITHOUT ID
  источник AS "Источник",
  length(rows) AS "Всего",
  length(filter(rows, (r) => r.статус = "решено")) AS "✅ Решено",
  length(rows) - length(filter(rows, (r) => r.статус = "решено")) AS "⬜ Осталось",
  round(length(filter(rows, (r) => r.статус = "решено")) / length(rows) * 100) + "%" AS "Прогресс"
FROM "LeetCode/Interview Problems"
WHERE интервью = true
GROUP BY источник
SORT источник ASC
```

## 🧱 Прогресс по сложности

```dataview
TABLE WITHOUT ID
  сложность AS "Сложность",
  length(rows) AS "Всего",
  length(filter(rows, (r) => r.статус = "решено")) AS "✅ Решено",
  length(rows) - length(filter(rows, (r) => r.статус = "решено")) AS "⬜ Осталось"
FROM "LeetCode/Interview Problems"
WHERE интервью = true
GROUP BY сложность
SORT сложность ASC
```

## 🔥 Сегодня решать

```dataview
TABLE WITHOUT ID
  choice(статус = "решено", "✅", "⬜") AS "✓",
  file.link AS "Задача",
  платформа AS "Платформа",
  источник AS "Источник",
  сложность AS "Сложность",
  попытки AS "Попытки"
FROM "LeetCode/Interview Problems"
WHERE интервью = true AND статус != "решено"
SORT порядок ASC, номер ASC, file.name ASC
LIMIT 12
```
