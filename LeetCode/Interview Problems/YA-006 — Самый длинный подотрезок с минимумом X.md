# YA-006 — Самый длинный подотрезок с минимумом X

> [!important] 🎯 Режим решения
> Сначала реши задачу по условию. Подсказка, идея, метаданные и решение спрятаны ниже, чтобы не подглядывать паттерн раньше времени.

## 📌 Условие

Дан массив целых чисел `nums` и число `X`. Нужно найти длину самого длинного непустого подотрезка, минимум на котором равен `X`.

Если таких подотрезков нет, вернуть `-1`.

```python
assert max_segment([1, 2, 3, 1], 2) == 2
assert max_segment([1, 3, 3, 1], 2) == -1
```

> [!info]- 🧭 Метаданные / спойлер
> Паттерн: один проход по сегментам, greedy.
> Похожие темы: arrays, segments, linear scan.

> [!tip]- 💡 Подсказка
> Подотрезок с минимумом `X` не может содержать элементы меньше `X`, но обязан содержать хотя бы один элемент, равный `X`.

> [!abstract]- 🧠 Идея
> Разбиваем массив на максимальные сегменты, где все элементы `>= X`. Внутри такого сегмента минимум будет равен `X`, если в сегменте хотя бы раз встретился сам `X`. Остается найти самый длинный такой сегмент.
>
> Время: `O(n)`. Память: `O(1)`.

> [!success]- ✅ Решение
> ```python
> def max_segment(nums: list[int], x: int) -> int:
>     best = -1
>     seg_len = 0
>     has_x = False
>
>     for value in nums:
>         if value >= x:
>             seg_len += 1
>             if value == x:
>                 has_x = True
>         else:
>             if has_x:
>                 best = max(best, seg_len)
>             seg_len = 0
>             has_x = False
>
>     if has_x:
>         best = max(best, seg_len)
>
>     return best
> ```
