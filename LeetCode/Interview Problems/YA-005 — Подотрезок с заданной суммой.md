# YA-005 — Подотрезок с заданной суммой

> [!important] 🎯 Режим решения
> Сначала реши задачу по условию. Подсказка, идея, метаданные и решение спрятаны ниже, чтобы не подглядывать паттерн раньше времени.

## 📌 Условие

Дан массив целых чисел. Нужно найти непустой подотрезок, то есть непрерывную последовательность, с заданной суммой `target`. Если такого подотрезка нет, вернуть `None`.

В этой версии задачи нужно вернуть индекс начала и конца подотрезка.

```python
assert find_target([9, -6, 5, 1, 4, -2], 10) == (2, 4)
```

На LeetCode похожая задача обычно требует вернуть количество таких подотрезков, а не границы.

> [!info]- 🧭 Метаданные / спойлер
> Паттерн: prefix sums, hash map.
> Похожие темы: arrays, hashmap, subarray sum.

> [!tip]- 💡 Подсказка
> Если сумма от `l` до `r` равна `target`, то `prefix[r] - prefix[l - 1] = target`. Значит, для текущего префикса надо искать уже встреченный префикс `prefix - target`.

> [!abstract]- 🧠 Идея
> Идем слева направо и поддерживаем текущую префиксную сумму. В словаре храним первую позицию, где встречалась каждая префиксная сумма. Для текущего `prefix` проверяем, был ли раньше `prefix - target`; если да, границы подотрезка восстановлены.
>
> В отличие от sliding window, этот подход работает и с отрицательными числами.
>
> Время: `O(n)`. Память: `O(n)`.

> [!success]- ✅ Решение
> ```python
> def find_target(nums: list[int], target: int) -> tuple[int, int] | None:
>     first_pos = {0: -1}
>     prefix = 0
>
>     for r, value in enumerate(nums):
>         prefix += value
>         need = prefix - target
>
>         if need in first_pos:
>             l = first_pos[need] + 1
>             return (l, r)
>
>         if prefix not in first_pos:
>             first_pos[prefix] = r
>
>     return None
> ```
