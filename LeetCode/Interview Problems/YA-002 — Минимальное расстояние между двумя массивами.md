# YA-002 — Минимальное расстояние между двумя массивами

> [!important] 🎯 Режим решения

## 📌 Условие

Даны два массива целых чисел `a` и `b`. Нужно найти минимальное расстояние между любыми двумя элементами, где один элемент берется из массива `a`, а другой из массива `b`.

Расстояние между элементами определяется как модуль разности:

```python
abs(a[i] - b[j])
```

```python
assert min_distance([0], [1]) == 1
assert min_distance([0, 10, 2], [5, 100, 12]) == 2
```

> [!info]- 🧭 Метаданные / спойлер
> Паттерн: сортировка, два указателя.
> Похожие темы: arrays, sorting, two pointers.

> [!tip]- 💡 Подсказка
> После сортировки массивов ближайшая пара находится локально: двигай указатель того массива, где текущий элемент меньше.

> [!abstract]- 🧠 Идея
> Сортируем оба массива и идем двумя указателями. На каждом шаге считаем расстояние между текущими элементами. Чтобы потенциально уменьшить расстояние, двигаем указатель на меньшем значении.
>
> Время: `O(n log n + m log m)`. Память: `O(1)`, если сортировать in-place, иначе `O(n + m)`.

> [!success]- ✅ Решение
> ```python
> def min_distance(a: list[int], b: list[int]) -> int:
>     if not a or not b:
>         raise ValueError("Invalid data")
>
>     a = sorted(a)
>     b = sorted(b)
>     i = 0
>     j = 0
>     min_dist = float("inf")
>
>     while i < len(a) and j < len(b):
>         current_dist = abs(a[i] - b[j])
>         min_dist = min(min_dist, current_dist)
>
>         if current_dist == 0:
>             return 0
>
>         if a[i] < b[j]:
>             i += 1
>         else:
>             j += 1
>
>     return min_dist
> ```
