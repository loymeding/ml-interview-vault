# YA-007 — Поиск анаграммы подстроки

> [!important] 🎯 Режим решения

## 📌 Условие

Даны текст `T` и строка `S`. Нужно найти в `T` подстроку, которая совпадает с `S` с точностью до перестановки букв.

Вернуть индекс первого вхождения или `-1`.

```python
assert find_anagram("reebok", "bee") == 1
```

> [!info]- 🧭 Метаданные / спойлер
> Паттерн: sliding window фиксированного размера, счетчики символов.
> Похожие темы: strings, hashmap, anagram.

> [!tip]- 💡 Подсказка
> Окно всегда должно иметь длину `len(S)`. Нужно быстро понимать, совпали ли частоты символов в окне с частотами в `S`.

> [!abstract]- 🧠 Идея
> Заводим `Counter` для нужных частот и скользящее окно длины `m = len(S)`. Чтобы не сравнивать два словаря на каждом шаге, храним `matched`: сколько уникальных символов сейчас совпадают по количеству. Когда `matched == unique`, окно является анаграммой.
>
> Время: `O(n)`. Память: `O(k)`, где `k` — число разных символов.

> [!success]- ✅ Решение
> ```python
> from collections import Counter
>
>
> def find_anagram(t: str, s: str) -> int:
>     n = len(t)
>     m = len(s)
>     if m == 0:
>         return 0
>     if m > n:
>         return -1
>
>     need = Counter(s)
>     window = Counter()
>     unique = len(need)
>     matched = 0
>
>     for i, ch_in in enumerate(t):
>         window[ch_in] += 1
>         if ch_in in need and window[ch_in] == need[ch_in]:
>             matched += 1
>         elif ch_in in need and window[ch_in] == need[ch_in] + 1:
>             matched -= 1
>
>         if i >= m:
>             ch_out = t[i - m]
>             if ch_out in need and window[ch_out] == need[ch_out]:
>                 matched -= 1
>             elif ch_out in need and window[ch_out] == need[ch_out] + 1:
>                 matched += 1
>             window[ch_out] -= 1
>
>         if matched == unique:
>             return i - m + 1
>
>     return -1
> ```
