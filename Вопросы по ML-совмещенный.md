## Что это за репозиторий

Obsidian-хранилище для подготовки к собеседованиям по Data Science. Пользователь изучает темы, записывает вопросы и ответы по ним. Весь контент на русском языке. Нет исходного кода, системы сборки или тестов.

## Структура папок

```
DataScienceDB/
├── Classic Machine Learning/   основной раздел по classical ML
├── Deep Learning/              отдельный раздел по DL
├── Изображения/                все вложенные картинки
├── 🏠 База знаний.md           общая главная всего vault
└── Вопросы по ML-совмещенный.md
```

Изображения (`Pasted image *.png`) теперь лежат в папке `Изображения/`. В карточках лучше использовать ссылки вида `![[Изображения/Pasted image XXXXXXXX.png]]`.

## Формат заметки

Каждая заметка начинается с YAML frontmatter:

```yaml
---
tags: [тема1, тема2]
сложность: низкая | средняя | высокая
статус: черновик | готово | требует доработки
---
```

Структура тела:
1. `> [!abstract] Суть` — ключевая мысль в одном предложении
2. `## Ответ` — основной развёрнутый ответ
3. `## Формула / Схема` — опционально
4. `## Каверзные вопросы` — блоки `> [!question]`
5. `## Связанные темы` — wiki-ссылки `[[...]]`

Шаблон: `Шаблоны/Шаблон новой темы.md`

## Банк вопросов

Файл `Банк вопросов.md` — очередь тем для разбора. Когда пользователь просит добавить вопросы — добавлять в нужный раздел чекбоксом `- [ ]`. Когда вопрос разобран и оформлен — переносить в раздел «Разобраны».

Общение с пользователем ведётся на русском языке.
