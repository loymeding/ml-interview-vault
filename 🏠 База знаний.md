## 📚 Разделы базы

```dataviewjs
const sections = [
  { name: "Classic Machine Learning", path: "Classic Machine Learning" },
  { name: "Deep Learning", path: "Deep Learning" }
];

function pagesForSection(path) {
  return dv.pages(`"${path}"`)
    .where(p => p.file.folder !== path && p.file.folder !== `${path}/Шаблоны`);
}

dv.table(
  ["Раздел", "Карточек", "✅ Готово", "✏️ Черновики", "🔴 Сложных"],
  sections.map(section => {
    const pages = pagesForSection(section.path);
    return [
      dv.fileLink(`${section.path}/🏠 Главная`, false, section.name),
      pages.length,
      pages.where(p => p["статус"] === "готово").length,
      pages.where(p => p["статус"] === "черновик").length,
      pages.where(p => p["сложность"] === "высокая").length
    ];
  })
);
```

## 🕒 Недавно добавленные карточки

```dataviewjs
const recentPages = dv.pages()
  .where(p =>
    (p.file.folder.startsWith("Classic Machine Learning/") || p.file.folder.startsWith("Deep Learning/")) &&
    !p.file.folder.endsWith("/Шаблоны")
  )
  .sort(p => p["создано"] ?? p.file.ctime, "desc")
  .array()
  .slice(0, 12);

dv.table(
  ["Заметка", "Раздел", "Создано", "Статус"],
  recentPages.map(p => [
    p.file.link,
    p.file.folder.split("/")[0],
    p["создано"] ?? "—",
    p["статус"] ?? "—"
  ])
);
```

## Как пользоваться базой

1. Начинать с нужного раздела: [[Classic Machine Learning/🏠 Главная|Classic Machine Learning]] или [[Deep Learning/🏠 Главная|Deep Learning]].
2. Для планового разбора смотреть `Банк вопросов` внутри раздела.
3. Для обзора готовности использовать локальные `🏠 Главная` и `🗺️ Индекс`.
4. Новые карточки создавать внутри соответствующего раздела, чтобы темы не смешивались.
