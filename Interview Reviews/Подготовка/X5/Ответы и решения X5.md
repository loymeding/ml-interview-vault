## Задачи и решения

### Task X5.A1 — Find Right Interval

**Статус:** 🟡 черновик решения принят

**Паттерн:** binary search по отсортированным `start`.

**Условие:** для каждого интервала найти индекс интервала с минимальным `start_j`, таким что `start_j >= end_i`.

**Черновик решения:**

```python
from bisect import bisect_left
from typing import List


def findRightInterval(intervals: List[List[int]]) -> List[int]:
    starts = []
    for i, (start, end) in enumerate(intervals):
        starts.append((start, i))

    starts.sort()
    sorted_starts = [start for start, _ in starts]

    answer = []

    for start, end in intervals:
        pos = bisect_left(sorted_starts, end)

        if pos == len(starts):
            answer.append(-1)
        else:
            answer.append(starts[pos][1])

    return answer
```

**Сложность:**

```text
Время: O(n log n)
Память: O(n)
```

**Что проверить / улучшить:**

- [ ] Проговорить, почему нужен именно `bisect_left`, а не `bisect_right`.
- [ ] Убрать неиспользуемый `start` во втором цикле или оставить для читаемости.
- [ ] Добавить тесты на равенство `end_i == start_j`.

### Task X5.A2 — Max Consecutive Ones с переворотом одного нуля

**Статус:** 🟡 черновик решения принят

**Паттерн:** sliding window / two pointers.

**Черновик решения через блоки единиц:**

```python
from typing import List


def max_ones(nums: List[int]) -> int:
    if not nums:
        return 0

    best = 1
    cur = 0
    prev = 0

    for x in nums:
        if x == 1:
            cur += 1
        else:
            best = max(best, prev + cur + 1)
            prev = cur
            cur = 0

    best = max(best, prev + cur + 1)

    if 0 not in nums:
        return len(nums)

    return min(best, len(nums))
```

**Что проверить / улучшить:**

- [ ] Сравнить с универсальным шаблоном sliding window `zeros <= 1`.
- [ ] Обсудить формулировку "максимум один ноль" vs "ровно один ноль".
- [ ] Убрать дополнительный проход `0 not in nums`, если хочется строго `O(n)` без второго прохода.

### Task X5.A3 — Minimize Maximum of Array

**Статус:** 🟡 черновик решения принят

**Паттерн:** prefix sum + математический инвариант.

**Ключевая идея:**

Операция переносит массу только влево. Для любого префикса `[0..i]` нельзя сделать максимум меньше, чем:

$$\Large \left\lceil \frac{\sum_{j=0}^{i} nums_j}{i+1} \right\rceil$$

Ответ:

$$\Large \max_i \left\lceil \frac{prefix_i}{i+1} \right\rceil$$

**Черновик решения:**

```python
def minimize_array_value(nums: list[int]) -> int:
    prefix_sum = 0
    best_max = 0

    for index, value in enumerate(nums):
        prefix_sum += value
        need_here = (prefix_sum + index) // (index + 1)
        best_max = max(best_max, need_here)

    return best_max
```

**Сложность:**

```text
Время: O(n)
Память: O(1)
```

**Что проверить / улучшить:**

- [ ] Уметь объяснить нижнюю границу через среднее по префиксу.
- [ ] Уметь объяснить достижимость этой границы операциями переноса влево.
- [ ] Проговорить формулу потолка: `(prefix_sum + index) // (index + 1)`.

### Task X5.SD1 — Кэширование полного ранжирования и pagination

**Статус:** 🟡 черновик решения принят

**Паттерн:** cache heavy computation + thin pagination wrapper.

**Идея:**

Тяжёлая функция строит полный ranking для `(user_id, target_tags, items_version)`, а публичная функция быстро отдаёт `iloc[offset:offset + limit]`.

**Черновик решения:**

```python
import pandas as pd
import numpy as np
from typing import List, Tuple
from functools import lru_cache


def score(item_id: int, user_id: str) -> float:
    return 1.0 - (hash(f"item:{item_id}-user:{user_id}") % 1000) / 1000.0


@lru_cache(maxsize=128)
def _get_full_ranking(user_id: str, target_tags: Tuple[int, ...], items_hash: int) -> pd.DataFrame:
    target_tags_set = set(target_tags)
    mask = items["tags"].apply(lambda item_tags: not target_tags_set.isdisjoint(item_tags))
    filtered = items[mask].copy()

    if filtered.empty:
        return filtered

    filtered["score"] = filtered["id"].apply(lambda item_id: score(item_id, user_id))
    sorted_items = filtered.sort_values("score", ascending=False).reset_index(drop=True)

    shuffled_indices = np.random.permutation(len(sorted_items))
    n_exploration = int(len(sorted_items) * 0.1)
    exploration_indices = shuffled_indices[:n_exploration]

    final_indices = sorted_items.index.to_numpy(copy=True)
    exploration_values = final_indices[exploration_indices]
    np.random.shuffle(exploration_values)
    np.put(final_indices, exploration_indices, exploration_values)

    return sorted_items.reindex(final_indices)


def get_ranked_items(
    items: pd.DataFrame,
    user_id: str,
    target_tags: List[int],
    exploration_fraction: float = 0.1,
    offset: int = 0,
    limit: int = 10,
) -> pd.DataFrame:
    items_hash = pd.util.hash_pandas_object(items).sum()
    full_ranking = _get_full_ranking(user_id, tuple(target_tags), items_hash)
    return full_ranking.iloc[offset: offset + limit]
```

**Что проверить / улучшить:**

- [ ] `items` внутри `_get_full_ranking` сейчас глобальный, хотя публичная функция принимает `items`.
- [ ] `exploration_fraction` не входит в ключ кэша и не используется внутри cached-функции.
- [ ] Python `hash()` нестабилен между процессами, для production нужен стабильный hash/seed.
- [ ] `pd.util.hash_pandas_object(items).sum()` может быть дорогим на каждом запросе.
- [ ] Нужно продумать invalidation: версия каталога, TTL, LRU size, user-level cache pressure.
- [ ] Рандомизация внутри cached-функции фиксируется на время жизни кэша; это может быть хорошо или плохо в зависимости от product logic.
