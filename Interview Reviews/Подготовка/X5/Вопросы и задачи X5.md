## Задачи и system design

### Задача 1 — Find Right Interval

**Теги:** `#x5 #тех #алго #binary-search`

Дан список интервалов `intervals`, таких, что `interval[i] = [start_i, end_i]`.

Для каждого интервала нужно найти индекс ближайшего правого для него интервала.
Если такого интервала нет, вернуть `-1`.

Ближайшим правым интервалом для интервала `i` будет интервал `j`:

```text
end_i <= start_j
```

при этом `start_j` должен быть минимальным среди всех подходящих.

`start_i` уникально для каждого интервала.

Примеры:

```text
[[1,2]] -> [-1]
[[3,4],[2,3],[1,2]] -> [-1,0,1]
```

Черновик решения:

```python
from bisect import bisect_left
from typing import List


def findRightInterval(intervals: List[List[int]]) -> List[int]:
    starts = []
    for i, (start, end) in enumerate(intervals):
        starts.append((start, i))

    starts.sort()
    sorted_starts = [start for start, _ in starts]

    answer = []

    for start, end in intervals:
        pos = bisect_left(sorted_starts, end)

        if pos == len(starts):
            answer.append(-1)
        else:
            answer.append(starts[pos][1])

    return answer
```

Сложность:

```text
Время: O(n log n)
Память: O(n)
```

### Задача 2 — Max Consecutive Ones с переворотом одного нуля

**Теги:** `#x5 #тех #алго #sliding-window #two-pointers`

Дан бинарный массив из `0` и `1`.
Можно перевернуть максимум один ноль в единицу.
Найти максимальную длину подряд идущих единиц после такого переворота.

Пример:

```text
[1, 0, 1, 1, 0] -> 4
```

Черновик решения:

```python
from typing import List


def max_ones(nums: List[int]) -> int:
    if not nums:
        return 0

    best = 1
    cur = 0
    prev = 0

    for x in nums:
        if x == 1:
            cur += 1
        else:
            best = max(best, prev + cur + 1)
            prev = cur
            cur = 0

    best = max(best, prev + cur + 1)

    if 0 not in nums:
        return len(nums)

    return min(best, len(nums))
```

### Задача 3 — Minimize Maximum of Array

**Теги:** `#x5 #тех #алго #prefix-sum #math`

Дан вектор неотрицательных целых чисел `nums`.
Разрешена единственная операция:

- выбрать индекс `i > 0` такой, что `nums[i] > 0`;
- уменьшить `nums[i]` на `1`;
- увеличить `nums[i - 1]` на `1`.

Требуется получить минимально возможное значение максимального элемента массива после применения произвольного количества таких операций.

Примеры:

```text
nums = [3, 7, 1, 6]       -> 5
nums = [1, 3, 5]          -> 3
nums = [10, 3, 5, 2, 7]   -> 10
```

Идея:

Минимизируем возможный максимум массива после операций переноса единицы влево.
Максимум нельзя сделать меньше, чем потолок среднего на любом префиксе, так как все лишние элементы с правой части префикса можно переносить только влево внутрь префикса.

Ответ:

```text
max_i ceil(prefix_sum[0..i] / (i + 1))
```

Черновик решения:

```python
def minimize_array_value(nums: list[int]) -> int:
    prefix_sum = 0
    best_max = 0

    for index, value in enumerate(nums):
        prefix_sum += value
        need_here = (prefix_sum + index) // (index + 1)
        best_max = max(best_max, need_here)

    return best_max
```

Сложность:

```text
Время: O(n)
Память: O(1)
```

### Задача 4 — System design / Python caching для ранжирования товаров

**Теги:** `#x5 #system-design #python #ranking #cache`

Проблема: на каждый вызов, даже за следующей страницей с `offset=10`, функция заново:

1. Фильтрует весь исходный DataFrame.
2. Считает score для всех отфильтрованных товаров.
3. Перемешивает весь результат.

Решение: закэшировать результат тяжёлых вычислений — полный отранжированный список для уникального запроса `(user_id, target_tags)`. Основная функция будет отдавать нужный срез из кэша.

Черновик решения:

```python
import pandas as pd
import numpy as np
from typing import List, Tuple
from functools import lru_cache


def score(item_id: int, user_id: str) -> float:
    return 1.0 - (hash(f"item:{item_id}-user:{user_id}") % 1000) / 1000.0


@lru_cache(maxsize=128)
def _get_full_ranking(user_id: str, target_tags: Tuple[int, ...], items_hash: int) -> pd.DataFrame:
    target_tags_set = set(target_tags)
    mask = items["tags"].apply(lambda item_tags: not target_tags_set.isdisjoint(item_tags))
    filtered = items[mask].copy()

    if filtered.empty:
        return filtered

    filtered["score"] = filtered["id"].apply(lambda item_id: score(item_id, user_id))
    sorted_items = filtered.sort_values("score", ascending=False).reset_index(drop=True)

    shuffled_indices = np.random.permutation(len(sorted_items))
    n_exploration = int(len(sorted_items) * 0.1)
    exploration_indices = shuffled_indices[:n_exploration]

    final_indices = sorted_items.index.to_numpy(copy=True)
    exploration_values = final_indices[exploration_indices]
    np.random.shuffle(exploration_values)
    np.put(final_indices, exploration_indices, exploration_values)

    return sorted_items.reindex(final_indices)


def get_ranked_items(
    items: pd.DataFrame,
    user_id: str,
    target_tags: List[int],
    exploration_fraction: float = 0.1,
    offset: int = 0,
    limit: int = 10,
) -> pd.DataFrame:
    items_hash = pd.util.hash_pandas_object(items).sum()
    full_ranking = _get_full_ranking(user_id, tuple(target_tags), items_hash)
    return full_ranking.iloc[offset: offset + limit]
```

> [!warning] Что нужно будет проверить при разборе
> В этом решении есть важные инженерные нюансы: глобальная переменная `items` внутри cached-функции, неиспользуемый `exploration_fraction`, нестабильность `hash()`, стоимость `hash_pandas_object`, инвалидирование кэша, размер кэша и воспроизводимость рандома.
