# 🎙️ Дашборд интервью

> Здесь не архив собеседований, а центр обратной связи: что спрашивали, где ответ просел, какие темы надо повторить и как меняется качество ответов от интервью к интервью.

## 🚦 Пульс собеседований

```dataviewjs
const reviews = dv.pages('"Interview Reviews/Разборы"')
  .where(p => (p.tags ?? []).includes("interview-review"))
  .array();

const tasks = dv.pages('"Interview Reviews/Разборы"').file.tasks;
const openHigh = tasks.where(t => !t.completed && t.priority === "high");
const openMedium = tasks.where(t => !t.completed && t.priority === "medium");
const totalQuestions = reviews.reduce((s, p) => s + (Number(p.questions) || 0), 0);
const avgScore = reviews.length
  ? (reviews.reduce((s, p) => s + (Number(p.avg_score) || 0), 0) / reviews.length).toFixed(2)
  : "—";
const red = reviews.reduce((s, p) => s + (Number(p.red_count) || 0), 0);
const yellow = reviews.reduce((s, p) => s + (Number(p.yellow_count) || 0), 0);
const green = reviews.reduce((s, p) => s + (Number(p.green_count) || 0), 0);

const kpis = [
  { icon: "🎙️", label: "Разборов", value: reviews.length, sub: "проведенных интервью", color: "#be123c" },
  { icon: "❓", label: "Вопросов", value: totalQuestions, sub: "разобрано поштучно", color: "#2563eb" },
  { icon: "📈", label: "Средний score", value: avgScore, sub: "по всем разборам", color: "#16a34a" },
  { icon: "🔥", label: "High priority", value: openHigh.length, sub: "открытых слабых мест", color: "#dc2626" },
  { icon: "🟡", label: "Medium", value: openMedium.length, sub: "надо подтянуть", color: "#ca8a04" },
  { icon: "🟢", label: "Сильных ответов", value: green, sub: "оценки 4-5/5", color: "#059669" },
  { icon: "🔴", label: "Провалов", value: red, sub: "оценки 1-2/5", color: "#b91c1c" },
  { icon: "🟡", label: "Пограничных", value: yellow, sub: "оценки 3/5", color: "#d97706" },
];

const grid = dv.el("div", "", {
  attr: {
    style: "display:grid;grid-template-columns:repeat(auto-fit,minmax(150px,1fr));gap:12px;margin:12px 0;"
  }
});

grid.innerHTML = kpis.map(k => `
  <div style="
    border:1px solid #e5e7eb;
    border-left:6px solid ${k.color};
    border-radius:12px;
    padding:14px 16px;
    background:linear-gradient(180deg,#fff,#f8fafc);
    box-shadow:0 1px 3px rgba(15,23,42,.08);
  ">
    <div style="font-size:24px;">${k.icon}</div>
    <div style="font-size:26px;font-weight:800;color:${k.color};margin-top:6px;">${k.value}</div>
    <div style="font-weight:700;color:#111827;">${k.label}</div>
    <div style="font-size:12px;color:#64748b;">${k.sub}</div>
  </div>
`).join("");
```

## 🔥 Боевой фокус

> [!danger] Правило
> High-priority вопросы — это не “почитать потом”, а материал для ближайшей тренировки вслух. После повторения отмечай чекбокс, а если карточка-ответ слабая, усиливай ее сразу.

```dataview
TASK
FROM "Interview Reviews/Разборы"
WHERE !completed AND priority = "high"
SORT score ASC, file.name ASC, source_q ASC
LIMIT 20
```

## ➕ Как добавлять новый разбор

> [!example] Конвейер после интервью
> 1. Скопировать безопасные итоговые отчеты в `Interview Reviews/Источники/<название-интервью>/`.
> 2. Создать карточку в `Interview Reviews/Разборы/` по шаблону [[Interview Reviews/_Шаблон разбора собеседования|Шаблон разбора собеседования]].
> 3. Заполнить метрики: число вопросов, средний score, красные, желтые и зеленые ответы.
> 4. Разнести вопросы в очередь повторения с inline-полями `score`, `priority`, `area`, `source_q`.
> 5. После повторения отмечать задачи чекбоксами, а карточки знаний усиливать по реальным провалам.
