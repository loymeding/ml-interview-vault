# 📅 Заметки А-Б тесты по дате создания

```dataview
TABLE WITHOUT ID
  создано as "Дата создания",
  file.link as "Заметка",
  тип,
  статус
FROM "А-Б тесты"
WHERE статус
  AND file.folder != "А-Б тесты"
SORT создано DESC
```
