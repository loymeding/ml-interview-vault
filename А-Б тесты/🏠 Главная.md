# 🏠 А-Б тесты

> [!tip] Цель
> Локальная главная раздела А-Б тесты: здесь собраны карточки по планированию экспериментов, статистическим критериям, расчету Sample Size и анализу результатов.

---

## 📊 Прогресс

```dataview
TABLE WITHOUT ID
  length(rows) as "📚 Заметок",
  length(filter(rows, (r) => r.статус = "готово")) as "✅ Готово",
  length(filter(rows, (r) => r.статус = "черновик")) as "✏️ Черновик",
  length(filter(rows, (r) => r.сложность = "высокая")) as "🔴 Сложных"
FROM "А-Б тесты"
WHERE статус
  AND file.folder != "А-Б тесты"
  AND file.folder != "А-Б тесты/Шаблоны"
GROUP BY true
```

## ⚠️ Требуют внимания

```dataview
TABLE WITHOUT ID file.link as "Заметка", file.folder as "Раздел", статус
FROM "А-Б тесты"
WHERE (статус = "черновик" OR статус = "требует доработки")
  AND file.folder != "А-Б тесты"
  AND file.folder != "А-Б тесты/Шаблоны"
SORT file.folder ASC
```

## 🔴 Сложные темы — повторить перед собесом

```dataview
TABLE WITHOUT ID file.link as "Заметка", file.folder as "Раздел", статус
FROM "А-Б тесты"
WHERE сложность = "высокая"
  AND file.folder != "А-Б тесты"
  AND file.folder != "А-Б тесты/Шаблоны"
```
