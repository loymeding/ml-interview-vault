# Объединение таблиц (JOINs)

> [!abstract] Суть
> JOIN — это операция, которая позволяет сопоставлять и объединять данные из двух или более таблиц в один набор строк на основе общего условия (обычно равенства ключей).

## Простыми словами

Представьте, что у вас есть два списка в Excel: в одном имена студентов и их ID, а в другом — ID студентов и их оценки. Чтобы узнать, какую оценку получил конкретный «Иван», вам нужно найти его ID в первом списке, перейти во второй список, найти там этот же ID и посмотреть оценку. JOIN делает это автоматически: он «склеивает» строки из двух таблиц по общим значениям.

## Ответ

**Формальное определение и типы**

Оператор JOIN выполняет горизонтальное объединение данных. Основные типы:
*   **INNER JOIN**: Возвращает только те строки, для которых есть соответствие в обеих таблицах. Если ключа нет в одной из таблиц, строка не попадет в результат.
*   **LEFT (OUTER) JOIN**: Возвращает все строки из левой таблицы и подходящие строки из правой. Если соответствия в правой таблице нет, на месте её колонок будут NULL.
*   **RIGHT (OUTER) JOIN**: Зеркальный аналог LEFT JOIN — берет всё из правой таблицы.
*   **FULL (OUTER) JOIN**: Объединяет LEFT и RIGHT JOIN. Возвращает все строки из обеих таблиц, заполняя пустоты NULL.
*   **CROSS JOIN**: Декартово произведение. Каждая строка первой таблицы соединяется с каждой строкой второй (результат: $N \times M$ строк).

**Разбор задач на количество строк (из файла)**

При расчете размера итоговой таблицы важно учитывать дубликаты в ключах:

1.  **LEFT JOIN: Таблица 1 (10 строк) и Таблица 2 (50 строк)**
    *   **Минимум**: 10 строк. Это произойдет, если для каждой строки из левой таблицы в правой нашлось 0 или 1 совпадение.
    *   **Максимум**: 500 строк. Если во всех 10 строках первой таблицы и во всех 50 строках второй таблицы указан один и тот же ID (ситуация «многие ко многим»), получится $10 \times 50 = 500$.

2.  **INNER JOIN: Таблица 1 (2 строки) и Таблица 2 (3 строки)**
    *   **Минимум**: 0 строк. Если ни один ключ из первой таблицы не совпал с ключами во второй.
    *   **Максимум**: 6 строк. Если все ключи в обеих таблицах одинаковые ($2 \times 3 = 6$).

## Аналог в Pandas

Для объединения DataFrame в Python используется метод `merge`:

```python
# Аналог LEFT JOIN
result = df1.merge(df2, on='key_column', how='left')
```

## Типичные ошибки

*   **Забытое условие ON**: В некоторых СУБД это приведет к ошибке, а в некоторых — к CROSS JOIN, который «повесит» сервер на больших данных.
*   **Дубли в ключах**: Если вы ожидаете связь 1-к-1, но в правой таблице ключи дублируются, LEFT JOIN увеличит количество строк в итоговой таблице, что может исказить агрегаты (например, сумму).

## Каверзные вопросы

> [!question] Как ведет себя JOIN, если в ключевом поле есть NULL?
> NULL не равен NULL. Поэтому строки с NULL в поле связи никогда не соединятся между собой ни в INNER JOIN, ни в LEFT JOIN. В LEFT JOIN строка с NULL из левой таблицы останется, но справа к ней ничего не приклеится.

> [!question] Можно ли сделать JOIN таблицы самой с собой?
> Да, это называется **SELF JOIN**. Обычно используется для иерархических структур (например, в таблице сотрудников есть колонка `manager_id`, которая ссылается на `employee_id` в этой же таблице).
