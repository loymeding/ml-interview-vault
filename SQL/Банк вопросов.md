## 📊 Прогресс по банку
```dataview
TABLE WITHOUT ID
  length(rows.completed) as "Выполнено",
  length(rows) as "Всего",
  round(length(rows.completed) / length(rows) * 100, 1) + "%" as "Прогресс"
FROM "SQL/Банк вопросов"
GROUP BY true
```
