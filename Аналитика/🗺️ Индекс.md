# 🗺️ Индекс — Аналитика

> [!abstract] Навигация
> Динамический индекс раздела. Новые карточки с полем `статус` появляются здесь автоматически.

## По разделам

```dataview
TABLE WITHOUT ID
  file.folder as "Раздел",
  rows.file.link as "Карточки"
FROM "Аналитика"
WHERE статус AND file.folder != "Аналитика"
GROUP BY file.folder
SORT file.folder ASC
```

## По уровню

```dataview
TABLE WITHOUT ID
  уровень as "Уровень",
  file.link as "Карточка",
  сложность as "Сложность",
  готовность as "Готовность"
FROM "Аналитика"
WHERE статус AND file.folder != "Аналитика"
SORT уровень ASC, file.name ASC
```

## По типам

```dataview
TABLE WITHOUT ID
  key as "Тип",
  length(rows) as "Количество",
  join(map(rows, (r) => link(r.file.path, r.file.name)), ", ") as "Карточки"
FROM "Аналитика"
WHERE статус AND file.folder != "Аналитика"
GROUP BY default(тип, "не задан")
SORT key ASC
```
