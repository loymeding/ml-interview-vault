# Функции активации

> [!abstract] Суть
> Функции активации добавляют в нейронную сеть нелинейность. Без них любая многослойная сеть выродилась бы в одну базовую линейную модель.

## Ответ

**Зачем нужны функции активации?**
Добавление нелинейности позволяет сети выучивать сложные закономерности. Без них суперпозиция линейных слоев остается линейной функцией.

**Основные типы:**

![[Pasted image 20260428083119.png]]

1. **Sigmoid (Сигмоида)**
   - **Свойства:** Сжимает в $(0, 1)$.
   - **Плюсы:** Удобна для вероятностей.
   - **Минусы:** Не центрирована вокруг нуля. Главная проблема — **затухание градиентов** на хвостах (производная $\approx 0$).

1. **Tanh (Гиперболический тангенс)**
   - **Свойства:** Сжимает в $(-1, 1)$.
   - **Плюсы:** Центрирована вокруг нуля, что ускоряет сходимость.
   - **Минусы:** Также страдает от затухания градиентов.

3. **ReLU (Rectified Linear Unit)**
   - **Свойства:** $f(z) = \max(0, z)$.
   - **Плюсы:** Быстро вычисляется, решает проблему затухания градиентов при $z > 0$.
   - **Минусы:** Проблема **«мертвых нейронов»** (dying ReLU) — если на вход всегда приходят отрицательные числа, то градиент ReLU = 0 при x ≤ 0, веса не обновляются,нейрон перестает обновляться.

4. **Leaky ReLU**
- `f(x) = max(αx, x)`, где α — маленькое число (обычно 0.01)
- При x ≤ 0: выход = αx (маленькое отрицательное), **производная = α**
- При x > 0: выход = x, производная = 1
- **Свойства:** Добавляет небольшой наклон для отрицательных значений. Успешно борется с «смертью» нейронов.

## Kaiming (He) Initialization

**Проблема**: При глубоких сетях с ReLU дисперсия активаций затухает или взрывается.

**Решение Kaiming He (2015)**: Инициализировать веса так, чтобы дисперсия сохранялась:

W ~ N(0, sqrt(2 / n_in))

где `n_in` — число входных нейронов (fan-in).

Множитель `2` компенсирует то, что ReLU "убивает" половину дисперсии (отрицательные значения обнуляются).
## Формула / Схема

- **Sigmoid:** $\sigma(z) = \frac{1}{1 + e^{-z}}$
- **Tanh:** $\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$
- **ReLU:** $f(z) = \max(0, z)$
- **Leaky ReLU:** $f(z) = \max(\alpha z, z)$, где $\alpha \approx 0.01$.

## Короткий пример

Пример использования в PyTorch:
```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 50),
    nn.ReLU(),           # Активация скрытого слоя
    nn.Linear(50, 1),
    nn.Sigmoid()         # Активация выхода для классификации
)
```

## Типичные ошибки

- **Sigmoid в скрытых слоях:** Использование сигмоиды во всех слоях глубокой сети почти гарантированно приведет к параличу обучения из-за затухания градиентов.
- **Игнорирование инициализации при ReLU:** При использовании ReLU критически важно использовать инициализацию Kaiming (He).

## Каверзные вопросы

> [!question] Почему симметричная область значений (Tanh) лучше несимметричной (Sigmoid)?
> Если все активации положительны, градиенты по весам будут одного знака, что заставляет обновление весов идти «зигзагами», замедляя обучение.
