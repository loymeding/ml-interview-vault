# Полносвязные нейронные сети (MLP)

> [!abstract] Суть
> Полносвязная нейронная сеть (многослойный перцептрон) — это универсальный аппроксиматор, состоящий из чередующихся линейных преобразований и нелинейных функций активации, где каждый нейрон одного слоя соединён со всеми нейронами следующего.

## Ответ

**От линейных моделей к нейросетям**
Логистическая регрессия — это классическая линейная модель. Её главная проблема заключается в том, что она может построить только линейную разделяющую границу. Чтобы обойти это ограничение, мы последовательно соединяем несколько преобразований, добавляя между ними нелинейность.

**Структура полносвязной сети**
Искусственная нейронная сеть — это сложная дифференцируемая функция, задающая отображение из исходного признакового пространства в пространство ответов, обучаемая end-to-end. Полносвязная сеть состоит из блоков, которые называются *скрытыми слоями*. 
Каждый такой слой производит линейное преобразование (умножение на матрицу весов $W$ и прибавление вектора смещений $b$), после чего к результату поэлементно применяется нелинейная функция активации.

**Зачем нужны нелинейности?**
Если мы построим глубокую сеть только из линейных слоев, без функций активации (таких как ReLU, Сигмоида или Tanh), то вся наша сеть математически выродится в одну единственную линейную модель. Это происходит потому, что линейная комбинация линейных функций всегда остается линейной функцией.

**Теорема Цыбенко**
Математическая мощь нейросетей подтверждается Теоремой об универсальном аппроксиматоре (Теорема Цыбенко, 1989 г.). Она доказывает, что нейросеть всего с одним скрытым слоем и сигмоидной функцией активации способна приблизить любую непрерывную функцию с любой наперед заданной точностью, если в скрытом слое будет достаточное количество нейронов.

## Формула / Схема

Математика двухслойной полносвязной сети (один скрытый слой) для задачи бинарной классификации:
$$X \to [z_1 = W_1 \cdot X + b_1] \to [a_1 = \sigma(z_1)] \to [z_2 = W_2 \cdot a_1 + b_2] \to [y = \sigma(z_2)]$$.

Где:
- $X$ — входной вектор признаков.
- $W_1, W_2$ — обучаемые матрицы весов.
- $b_1, b_2$ — обучаемые векторы смещений (bias).
- $\sigma$ — функция активации.

## Короткий пример

Реализация простой полносвязной сети на PyTorch:
```python
import torch.nn as nn

class FullyConnectedNet(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(FullyConnectedNet, self).__init__()
        self.fc1 = nn.Linear(input_size, hidden_size) # W1 и b1
        self.relu = nn.ReLU()                         # Нелинейность
        self.fc2 = nn.Linear(hidden_size, output_size)# W2 и b2

    def forward(self, x):
        out = self.relu(self.fc1(x))
        out = self.fc2(out)
        return out
```

## Типичные ошибки

- **Инициализация весов нулями:** Все нейроны слоя будут получать одинаковые градиенты и обновляться идентично, что не позволит сети выучить разные признаки.
- **Отсутствие функции активации:** Забыть поставить активацию между слоями, превратив нейросеть в обычную линейную регрессию.

## Каверзные вопросы

> [!question] Если по теореме Цыбенко сети с одним слоем достаточно, зачем использовать глубокие сети?
> Для сложной функции один слой должен быть экспоненциально широким, что ведет к переобучению. Глубокие сети выучивают иерархические признаки (от простых к сложным) с кратно меньшим числом параметров.
