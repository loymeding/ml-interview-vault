# Операция свёртки и её параметры (Convolution)

> [!abstract] Суть
> Свёртка — это скользящее окно с обучаемыми весами, которое радикально снижает число параметров сети и обеспечивает инвариантность к сдвигу (объект распознается в любом месте кадра).

## Ответ

**Почему не подходят полносвязные сети (MLP)?**
Для картинки 224x224x3 полносвязный слой потребовал бы миллионы параметров, что ведет к переобучению. К тому же, MLP «вытягивает» картинку в вектор, разрушая пространственные связи между пикселями.

**Идея свёртки**
Мы берем небольшое «ядро» (например, 3x3) и скользим им по изображению. В каждой точке вычисляется сумма произведений пикселей на веса ядра. Одно и то же ядро используется для всей картинки (**parameter sharing**).

**Ключевые параметры:**
1.  **Kernel size (Размер ядра):** Стандарт — 3x3. Реже 5x5 или 7x7.
2.  **Stride (Шаг):** На сколько пикселей сдвигается окно. По умолчанию 1. Stride=2 уменьшает картинку вдвое.
3.  **Padding (Дополнение):** Рамка из нулей по краям. Нужна, чтобы сохранить размер картинки после свёртки. Для ядра 3x3 нужен `padding=1`.
4.  **Channels (Каналы):** Глубина тензора. Вход — 3 (RGB), выход — количество фильтров в слое.

## Формула / Схема

**Размер выхода:**
$$Output = \Large \frac{Input - Kernel + 2 \cdot Padding}{Stride} + 1$$

**Количество параметров:**
$$\Large Params = (K \times K \times C_{in} + 1) \times C_{out}$$

## Короткий пример

Реализация в PyTorch:
```python
import torch.nn as nn

conv = nn.Conv2d(
    in_channels=3,   # Вход (RGB)
    out_channels=64, # Количество фильтров
    kernel_size=3,   # Ядро 3x3
    stride=1, 
    padding=1,       # Сохраняем размер
    bias=False       # Выключаем, если далее BatchNorm
)
```

## Типичные ошибки

- **Bias + BatchNorm:** Оставлять `bias=True`, если следующим слоем идет Batch Normalization. BN всё равно вычтет среднее, сделав bias бесполезным.
- **Размерность входа:** Забыть, что `Conv2d` ждет 4D тензор `(Batch, Channels, Height, Width)`.

## Каверзные вопросы

> [!question] Является ли свёртка линейной операцией?
> Да, свёртка — это линейное преобразование, частный случай матричного умножения с разреженной матрицей и повторяющимися весами.
