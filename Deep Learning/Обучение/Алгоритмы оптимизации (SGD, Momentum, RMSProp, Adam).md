# Алгоритмы оптимизации (SGD, Momentum, RMSProp, Adam)

> [!abstract] Суть
> Оптимизаторы управляют тем, как именно обновляются веса. Современный стандарт — адаптивные алгоритмы (Adam), которые подбирают шаг для каждого веса отдельно и используют инерцию.

## Ответ

**1. SGD (Stochastic Gradient Descent)**
Базовый метод: идем против градиента.
- **Минусы:** Медленно сходится, сильно «дёргается» (осциллирует) в узких оврагах ландшафта потерь.

**2. Momentum (SGD с моментом)**
Накапливает «инерцию» прошлых градиентов.
- **Идея:** Работает как тяжелый шар. Если градиент долго указывает в одну сторону, шар разгоняется. Это сглаживает случайные колебания и помогает преодолевать локальные минимумы.

**3. RMSProp**
Адаптивный шаг для каждого параметра.
- **Идея:** Делит шаг на корень из среднего квадрата прошлых градиентов. Если по какому-то весу градиент огромный — шаг уменьшается, если маленький — увеличивается.

**4. Adam (Adaptive Moment Estimation)**
Комбинирует **Momentum** и **RMSProp**.
- **Плюсы:** Быстрая сходимость, отлично работает «из коробки» почти на любых задачах. Стандарт индустрии.

## Формула / Схема

- **Momentum:** $\Large v_t = \beta v_{t-1} + (1-\beta)g_t \quad \Rightarrow \quad \theta \leftarrow \theta - \eta v_t$
- **Adam:** $\Large \theta \leftarrow \theta - \frac{\eta \hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon}$ (использует два «момента» — среднее градиента и среднее квадрата градиента).

## Короткий пример

Использование в PyTorch:
```python
import torch.optim as optim

# Adam - стандарт (обычно lr=1e-3)
optimizer = optim.Adam(model.parameters(), lr=0.001)

# SGD с моментом - часто лучше для Computer Vision
optimizer = optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
```

## Типичные ошибки

- **Использование только Adam:** В некоторых задачах (особенно CV) классический SGD с моментом и расписанием LR (scheduler) может дать лучшее качество на тесте, чем Adam.
- **Отсутствие Weight Decay:** Для Adam нужно использовать версию `AdamW` для корректной L2-регуляризации.

## Каверзные вопросы

> [!question] Почему Adam иногда хуже SGD на тестовой выборке?
> Adam быстрее находит минимум, но этот минимум часто бывает «острым». Малейшее отклонение данных (переход к тесту) резко увеличивает ошибку. SGD находит более «плоские» минимумы, которые лучше обобщаются.
