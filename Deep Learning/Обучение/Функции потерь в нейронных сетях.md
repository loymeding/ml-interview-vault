# Функции потерь в нейронных сетях

> [!abstract] Суть
> Функции потерь (Loss functions) определяют, как сеть вычисляет ошибку и какой градиент будет использован для обновления весов. Выбор зависит от типа задачи (регрессия, классификация, сегментация).

## 1. Регрессия

| Loss | Формула | Особенности | Когда использовать |
|------|---------|-------------|--------------------|
| **MSE** (L2) | $\frac{1}{n}\sum(y-\hat{y})^2$ | Квадратичный штраф, чувствительна к выбросам | Стандарт для регрессии без аномалий |
| **MAE** (L1) | $\frac{1}{n}\sum|y-\hat{y}|$ | Линейный штраф, робастна к выбросам | Грязные данные, много выбросов |
| **Huber** | Гибрид L1 и L2 | Гладкая в 0 (как L2), линейная при больших ошибках | Компромисс между точностью и робастностью |
| **Quantile** | $\tau \cdot |e|$ или $(1-\tau) \cdot |e|$ | Оптимизирует конкретный квантиль | Интервальные прогнозы |

## 2. Классификация

### Binary Cross-Entropy (BCE)
Для бинарной классификации (1 нейрон на выходе с сигмоидой).
$$\text{BCE} = -[y \log(\hat{y}) + (1-y) \log(1-\hat{y})]$$
- **Плюс:** Математически обоснована (MLE), градиент не затухает при больших ошибках.
- **Минус:** Плохо работает при сильном дисбалансе классов.

### Categorical Cross-Entropy (CCE)
Для многоклассовой классификации (Softmax на выходе).
$$\text{CCE} = -\sum y_c \log(\hat{y}_c)$$
- **Sparse CCE:** То же самое, но принимает индексы классов вместо One-Hot векторов (экономит память).

### Focal Loss
Модификация BCE для борьбы с дисбалансом.
$$\text{FL} = -\alpha(1 - \hat{y})^\gamma \log(\hat{y})$$
- **Суть:** Уменьшает вклад «лёгких» примеров (где сеть уверена), заставляя её фокусироваться на сложных. Параметр $\gamma$ регулирует степень фокусировки.

## 3. Специальные задачи

- **Hinge Loss:** Используется в SVM-подобных слоях, создаёт «зазор» (margin).
- **Triplet Loss:** Используется в метрическом обучении (FaceID). Сближает похожие объекты и раздвигает разные.
- **Dice Loss:** Стандарт для сегментации изображений. Основана на пересечении областей (F1-score), устойчива к дисбалансу фона и объекта.
- **KL Divergence:** Используется в дистилляции знаний и VAE для сравнения распределений.
- **CTC Loss:** Для задач, где длина входа и выхода не совпадает (распознавание речи, OCR).

## Сводная таблица выбора

| Задача | Рекомендуемый Loss | Альтернатива |
|--------|-------------------|--------------|
| Регрессия | **MSE** | Huber (при выбросах) |
| Бинарная классификация | **BCE** | Focal Loss (при дисбалансе) |
| Многоклассовая (1000+ классов) | **Sparse CCE** | CCE |
| Сегментация изображений | **Dice Loss** | BCE + Dice |
| Face Recognition / Embeddings | **Triplet Loss** | Contrastive Loss |

## Короткий пример
В задаче детекции объектов (например, YOLO) используется комбинация нескольких функций потерь: **BCE** для определения наличия объекта, **CCE** для классификации и **MSE/Huber** для уточнения координат рамки (bounding box).

## Типичные ошибки
- Использовать CCE для классификации, где объекты могут принадлежать сразу к нескольким классам (нужно использовать BCE для каждого нейрона).
- Забывать, что MSE в нейросетях может приводить к взрыву градиентов при очень больших ошибках.
