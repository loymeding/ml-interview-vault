# Batch Normalization (Пакетная нормализация)

> [!abstract] Суть
> Batch Normalization (BN) нормализует данные внутри сети (среднее 0, дисперсия 1) по каждому мини-батчу. Это радикально ускоряет обучение и стабилизирует глубокие сети.

## Ответ

**Проблема: Внутренний ковариатный сдвиг**
Когда веса одного слоя меняются, распределение его выходов тоже меняется. Следующему слою приходится постоянно переучиваться под новый масштаб данных. Это замедляет обучение.

**Как работает BN на обучении:**
1.  **Нормализация:** Для текущего батча вычисляются среднее $\mu$ и дисперсия $\sigma^2$. Данные центрируются и масштабируются.
2.  **Восстановление (Scale & Shift):** Применяются обучаемые параметры $\gamma$ (масштаб) и $\beta$ (сдвиг). Это нужно, чтобы сеть сама могла вернуть нужный масштаб, если «чистая» нормализация мешает обучению.

**Как работает BN на инференсе:**
На этапе теста (`model.eval()`) у нас может не быть батча. Поэтому слой использует **скользящее среднее** (running statistics), которое он накопил во время обучения.

**Зачем нужен BN?**
- Можно использовать больший **Learning Rate**.
- Меньшая зависимость от начальной инициализации весов.
- Работает как легкая форма регуляризации.

## Формула / Схема

$$\Large X_{norm} = \frac{X - \mu_{batch}}{\sqrt{\sigma^2_{batch} + \epsilon}}, \quad Y = \gamma X_{norm} + \beta$$

## Короткий пример

Использование в PyTorch (обычно ставится *перед* активацией):
```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(100, 50, bias=False), # bias не нужен, так как у BN есть свой сдвиг
    nn.BatchNorm1d(50),
    nn.ReLU()
)
```

## Типичные ошибки

- **Маленький батч:** Если `batch_size` очень мал (2-4), оценки среднего и дисперсии будут «шумными», и BN может даже ухудшить обучение.
- **Забыть `model.eval()`:** На тесте BN начнет считать статистику по тестовому объекту, что приведет к неверным результатам.
- **Оставлять `bias` в слое перед BN:** Слой BN всё равно вычтет среднее, поэтому `bias` в предыдущем линейном или сверточном слое бесполезен и просто тратит память.

## Каверзные вопросы

> [!question] В чем истинная причина успеха BN согласно современным исследованиям?
> Изначально думали про «ковариатный сдвиг», но сейчас доказано, что BN просто делает ландшафт функции потерь намного более гладким, позволяя делать большие шаги без риска «взрыва».
