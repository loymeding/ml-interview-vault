# Регуляризация в DL — Dropout

> [!abstract] Суть
> Dropout — это метод регуляризации, который случайно «выключает» нейроны во время обучения. Это заставляет сеть быть устойчивой и не полагаться на конкретные связи, работая как неявное ансамблирование.

## Ответ

**Как это работает?**
На каждом шаге обучения каждый нейрон с вероятностью $p$ (например, $0.5$) временно отключается (его выход зануляется).
- **Коадаптация:** Без Dropout нейроны могут начать «подстраиваться» друг под друга, компенсируя ошибки соседа. Dropout заставляет каждый нейрон выучивать полезные признаки независимо.
- **Ансамблирование:** Каждая итерация с Dropout — это обучение новой «урезанной» подсети. На инференсе, когда работают все нейроны, мы фактически усредняем предсказания миллионов таких подсетей.

**Inverted Dropout**
Чтобы сумма активаций на следующем слое не выросла вдвое при включении всех нейронов на тесте, во время обучения выжившие нейроны масштабируются (делятся на $1-p$). Благодаря этому на этапе `eval` ничего менять не нужно.

**Где применять?**
- **Полносвязные слои:** $p=0.5$ (стандарт).
- **Сверточные слои:** $p=0.1 \dots 0.2$ (редко, так как там и так мало параметров).

## Формула / Схема

**На обучении:**
$$y = \frac{1}{1-p} \cdot x \odot \text{mask}, \quad \text{mask} \sim \text{Bernoulli}(1-p)$$

## Короткий пример

Использование в PyTorch:
```python
import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(100, 50)
        self.dropout = nn.Dropout(p=0.5)

    def forward(self, x):
        x = torch.relu(self.fc(x))
        x = self.dropout(x) # Выключается на model.eval()
        return x
```

## Типичные ошибки

- **Забыть `model.eval()`:** Если не вызвать этот метод перед тестированием, Dropout продолжит занулять нейроны случайным образом, что снизит точность и сделает предсказания нестабильными.
- **Слишком большой $p$ при недообучении:** Если модель и так слабая, Dropout сделает её ещё слабее.

## Каверзные вопросы

> [!question] Зачем нужно делить на $1-p$ во время обучения?
> Это сохраняет математическое ожидание (среднюю амплитуду) сигнала. Без этого на инференсе, когда включатся все нейроны, следующий слой получит сигнал в 2 раза сильнее, чем тот, на котором он учился.
