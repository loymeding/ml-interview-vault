# Инициализация весов в глубоких сетях

> [!abstract] Суть
> Случайная инициализация весов критически важна для нарушения симметрии нейронов. Если проинициализировать все веса одинаково, все нейроны будут вычислять одно и то же. Дисперсия весов должна быть откалибрована: **Xavier** — для Tanh/Sigmoid, **Kaiming** — для ReLU.

## Ответ

### 1. Проблема симметрии (нулевые веса)

Если $W = 0$, все выходы слоя $X \cdot W = 0$. Все градиенты $\nabla_W L = X^T \nabla_{out} L$ одинаковы. Нейроны навсегда останутся идентичными. Bias инициализировать нулями **безопасно**.

### 2. Математика дисперсии

$$\Large \text{Var}(s) = n \cdot \text{Var}(w) \cdot \text{Var}(x)$$

где:
- $n$ — количество входов нейрона (fan-in)
- $\text{Var}(w)$ — дисперсия весов
- $\text{Var}(x)$ — дисперсия входных данных

Для стабильности нужно $\text{Var}(s) \approx \text{Var}(x)$, значит $\text{Var}(w) = \frac{1}{n}$.

### 3. Xavier (Glorot) — 2010

$$\Large W \sim \mathcal{N}\!\left(0,\; \frac{2}{n_{\text{in}} + n_{\text{out}}}\right)$$

где $n_{\text{in}}$, $n_{\text{out}}$ — число входных и выходных нейронов.

### 4. Kaiming (He) — 2015

ReLU зануляет половину входов → дисперсия падает в 2 раза. Компенсируем:

$$\Large W \sim \mathcal{N}\!\left(0,\; \frac{2}{n_{\text{in}}}\right)$$

## Формула / Схема

| Активация | Метод | $\text{Var}(W)$ |
|--|--|--|
| Linear, Tanh, Sigmoid | Xavier | $\frac{2}{n_{\text{in}} + n_{\text{out}}}$ |
| ReLU, Leaky ReLU | Kaiming | $\frac{2}{n_{\text{in}}}$ |

## Короткий пример

```python
import torch.nn as nn

layer = nn.Linear(100, 50)
nn.init.xavier_normal_(layer.weight)        # для Tanh
nn.init.kaiming_normal_(layer.weight, mode='fan_in', nonlinearity='relu')  # для ReLU
nn.init.zeros_(layer.bias)                  # bias — нулями
```

## Типичные ошибки

- **Xavier для сетей с ReLU:** дисперсия будет падать вдвое каждый слой → сигнал затухнет.
- **Фиксированный масштаб $W \sim \mathcal{N}(0, 0.01)$:** не учитывает $n_{\text{in}}$ конкретного слоя.

## Каверзные вопросы

> [!question] Что если все веса одинаковы, но не нули (например, $W_i = 0.42$)?
> Симметрия **останется**. Все нейроны вычислят одинаковый выход и получат идентичный градиент. Критически важна **случайность**.
