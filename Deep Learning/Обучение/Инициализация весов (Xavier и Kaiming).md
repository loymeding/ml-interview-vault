# Инициализация весов (Xavier и Kaiming)

> [!abstract] Суть
> Правильная инициализация предотвращает затухание/взрыв градиентов на старте. Она «разрушает симметрию» нейронов и поддерживает стабильную дисперсию активаций.

## Ответ

**Почему нельзя инициализировать нулями?**
Если веса одинаковы (например, 0), все нейроны слоя выдадут идентичный результат и получат одинаковые градиенты. Сеть не сможет выучить разные признаки.

**Проблема дисперсии**
При проходе через слои дисперсия данных может экспоненциально расти или падать. Это приводит либо к насыщению активаций (Sigmoid/Tanh), либо к затуханию сигнала.

**Метод Xavier (Glorot)**
Подходит для симметричных функций активации (`tanh`, `sigmoid`).
- **Идея:** Сохранить дисперсию активаций одинаковой на входе и выходе слоя.
- **Формула:** $\Large Var(w) = \frac{2}{n_{in} + n_{out}}$.
**n_in​ — это количество входных нейронов слоя (размерность входа)**  
**n_out​ — это количество выходных нейронов слоя (размерность выхода)**

**Метод Kaiming (He)**
Разработан специально для **ReLU**.
- **Идея:** ReLU обнуляет половину распределения, уменьшая дисперсию в 2 раза. Чтобы это компенсировать, дисперсия весов должна быть в 2 раза больше, чем в методе Xavier.
- **Формула:** $\Large Var(w) = \frac{2}{n_{in}}$.

## Формула / Схема

- **Xavier (равномерное):** $\Large w \sim U\left[-\frac{\sqrt{6}}{\sqrt{n_{in} + n_{out}}}, \frac{\sqrt{6}}{\sqrt{n_{in} + n_{out}}}\right]$
- **Kaiming (нормальное):** $\Large w \sim \mathcal{N}\left(0, \frac{2}{n_{in}}\right)$

## Короткий пример

Явная инициализация в PyTorch:
```python
import torch.nn as nn

# Для слоя с ReLU
nn.init.kaiming_normal_(self.fc1.weight, nonlinearity='relu')
# Для слоя с Tanh
nn.init.xavier_uniform_(self.fc2.weight)
# Смещения (bias) всегда инициализируем нулями
nn.init.constant_(self.fc1.bias, 0)
```

## Типичные ошибки

- **Xavier для ReLU:** В глубоких сетях это приведет к постепенному затуханию сигнала (дисперсия будет падать вдвое на каждом слое).
- **Случайные смещения:** Инициализировать bias случайными числами не нужно, достаточно нулей.

## Каверзные вопросы

> [!question] Почему логистическая регрессия работает с нулевой инициализацией, а MLP — нет?
> В регрессии каждый вес связан с уникальным входным признаком. В MLP признаки для скрытых слоев генерируют сами нейроны — если они «клоны», они не смогут разделиться.
