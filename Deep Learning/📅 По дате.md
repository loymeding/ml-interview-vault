# 📅 Deep Learning — по дате

> Хронологический обзор карточек внутри раздела Deep Learning.

```dataview
TABLE WITHOUT ID
  link(file.path, file.name) as "Заметка",
  создано as "Дата",
  сложность as "Сложность",
  статус as "Статус"
FROM "Deep Learning"
WHERE создано != null
  AND file.folder != "Deep Learning"
  AND file.folder != "Deep Learning/Шаблоны"
SORT создано DESC, file.name ASC
```

---

## Сводка по датам

```dataview
TABLE WITHOUT ID
  создано as "Дата",
  length(rows) as "Кол-во заметок",
  join(map(rows, (r) => link(r.file.path, r.file.name)), ", ") as "Заметки"
FROM "Deep Learning"
WHERE создано != null
  AND file.folder != "Deep Learning"
  AND file.folder != "Deep Learning/Шаблоны"
GROUP BY создано
SORT создано DESC
```
