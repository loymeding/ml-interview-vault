# Понижение размерности (PCA, t-SNE, UMAP)

> [!abstract] Суть
> Понижение размерности нужно для борьбы с "проклятием размерности", визуализации и сжатия признаков. PCA — линейный (дисперсия), t-SNE/UMAP — нелинейные (соседство/многообразия).

## PCA (Principal Component Analysis)

**Цель:** Найти новые ортогональные оси (главные компоненты), вдоль которых данные имеют максимальный дисперсию.
- **Линейный метод:** Хорошо работает, если данные лежат на плоскости/гиперплоскости.
- **Математика (Матрица ковариаций):** PCA находит собственные векторы и собственные значения ковариационной матрицы данных $X^T X$. Собственные векторы задают направления новых осей, а собственные значения — долю дисперсии вдоль этих осей.
- **Связь с SVD:** На практике PCA часто вычисляют через Сингулярное разложение (SVD) центрированной матрицы данных $X = U \Sigma V^T$. Главные компоненты — это столбцы $V$, а дисперсии пропорциональны квадратам сингулярных чисел из $\Sigma$.
- **Выбор числа компонент:** Выбирают столько компонент, чтобы сумма их собственных значений (Cumulative Explained Variance) покрывала желаемую долю исходной дисперсии (например, 95%).
- **Восстановление (Reconstruction):** Данные можно восстановить в исходную размерность обратным преобразованием $\hat{X} = X_{pca} V^T$, но с **ошибкой аппроксимации** — потерей информации из отброшенных компонент.
- **Whitening (Осветление):** Дополнительный шаг после PCA, делящий компоненты на их стандартное отклонение (сферизация данных).
- **Kernel-PCA:** Применение "Kernel Trick" (как в SVM) для нахождения нелинейных главных компонент.

## t-SNE (t-distributed Stochastic Neighbor Embedding)

**Цель:** Визуализация кластеров.
- **Математика:** Минимизирует дивергенцию Кульбака-Лейблера (KL-Divergence) между распределением вероятностей соседства в исходном пространстве и в 2D.
- **Нелинейный:** Сохраняет только локальные расстояния (кто с кем рядом).
- **Параметр Perplexity:** Управляет балансом между локальным и глобальным вниманием (аналог числа соседей).

## UMAP (Uniform Manifold Approximation and Projection)

**Цель:** Современная альтернатива t-SNE.
- **Математика:** Теория римановых многообразий и топологии.
- **Преимущества перед t-SNE:**
    - Намного быстрее.
    - Лучше сохраняет **глобальную структуру** (соотносительные расстояния между кластерами имеют смысл).
    - Имеет метод `transform()` (можно применить к новым данным).

## Сравнение

## Каверзные вопросы

> [!question] Какие риски при снижении размерности перед обучением модели?
> - **Потеря информации** — компоненты с малой дисперсией могут содержать сигнал для целевой переменной
> - **Data leakage** — если PCA обучается на всей выборке (включая тест), статистика теста просачивается в обучение → нужно fit только на train
> - **Потеря интерпретируемости** — признаки становятся линейными комбинациями исходных
> - **t-SNE нельзя применять как preprocessing** — не имеет `transform` для новых данных, только для визуализации

> [!question] Почему t-SNE использует t-распределение, а не Гауссово в 2D?
> Для решения **Crowding Problem** (проблемы скученности). В многомерном пространстве вокруг точки помещается намного больше соседей, чем в 2D. Если использовать Гауссиану в 2D, всем точкам не хватит места, и они сольются. t-распределение имеет **тяжёлые хвосты**, что позволяет далеким (но умеренно близким) точкам разойтись в 2D без штрафа, сохраняя локальные кластеры.




## Короткий пример

Тему «PCA, t-SNE и UMAP» полезно привязывать к визуализации высокоразмерных эмбеддингов или сжатия коррелированных признаков. Если нужно быстро "посмотреть" на данные — **UMAP** обычно лучший выбор. Если нужно строгое сжатие для модели — **PCA**.

## Типичные ошибки

- Использовать t-SNE как полноценный метод подготовки признаков для продакшн-модели без оговорок про нестабильность и искажения глобальной структуры.
- Считать, что компоненты PCA автоматически имеют удобную прикладную интерпретацию.
