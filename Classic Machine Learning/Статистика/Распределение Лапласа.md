# Распределение Лапласа

> [!abstract] Суть
> Распределение Лапласа — это «остроконечный» аналог нормального распределения с более тяжелыми хвостами, который менее чувствителен к выбросам и напрямую связан с L1-регуляризацией.

## Ответ

Распределение Лапласа (двойное экспоненциальное) часто называют «остроконечным кузеном» распределения Гаусса. В отличие от нормального распределения, оно использует модуль разности вместо квадрата, что делает его более устойчивым (робастным) к экстремальным значениям.

**Ключевые особенности:**
- **Устойчивость к выбросам:** В отличие от Гаусса, который сильно штрафует большие отклонения (из-за квадрата в экспоненте), Лаплас штрафует их линейно.
- **Параметры:** Описывается центром ($\mu$) и масштабом ($b$).
- **Связь с медианой:** Оценка максимального правдоподобия (MLE) для центра распределения Лапласа — это **медиана** выборки, в то время как для Гаусса — это среднее арифметическое.

## Формула / Схема

Плотность вероятности (PDF):
$$f(x \mid \mu, b) = \frac{1}{2b} \exp\left(-\frac{|x - \mu|}{b}\right)$$

Где:
- $\mu$ — положение (loc), совпадает с медианой.
- $b$ — масштаб (scale), равен среднему абсолютному отклонению (MAD).

## Короткий пример

**Демонстрация устойчивости (робастности):**
Зарплаты: `50, 55, 52, 48, 1 000 000`
- **Гаусс (среднее):** $\approx 200\,000$ (один директор «взломал» статистику).
- **Лаплас (медиана):** $52$ (адекватная оценка типичной зарплаты).

```python
import numpy as np

# Оценка параметра b (масштаб) через MAD
def estimate_laplace_params(x):
    mu = np.median(x)
    b = np.mean(np.abs(x - mu))
    return mu, b
```

## Типичные ошибки

- **Путаница параметров:** Думать, что $b$ — это стандартное отклонение. На самом деле $b$ — это среднее абсолютное отклонение от медианы.
- **Использование среднего:** Пытаться оценить центр распределения Лапласа через `np.mean()`. Правильно — через `np.median()`.

## Каверзные вопросы

> [!question] Как распределение Лапласа связано с Lasso-регуляризацией (L1)?
