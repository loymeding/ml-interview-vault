# Основы и классические модели временных рядов

> [!abstract] Суть
> Временной ряд — это последовательность данных, где важен порядок. Главное отличие от классического ML — наличие зависимости между соседними точками (автокорреляция) и наличие тренда/сезонности.

## Основные понятия

### 1. Компоненты ряда
$$Y_t = T_t + S_t + E_t$$
- **$T_t$ (Trend):** Плавное изменение среднего уровня на длительном интервале.
- **$S_t$ (Seasonality):** Повторяющиеся циклы (день, неделя, год).
- **$E_t$ (Error/Noise):** Случайные колебания.

### 2. Стационарность
Ряд стационарен, если его матожидание и дисперсия **не меняются во времени**. Большинство классических моделей (ARIMA) требуют стационарности.
- **Как проверить:** Тест Дики-Фуллера (ADF).
- **Как добиться:** Взятие разностей ($y_t - y_{t-1}$), логарифмирование.

## Классические модели

### AR (Autoregression)
Предсказываем значение через взвешенную сумму **предыдущих** значений этого же ряда.

### MA (Moving Average)
Предсказываем значение через взвешенную сумму **ошибок** (шоков) предыдущих шагов. Не путать со скользящим средним как методом сглаживания!

### ARIMA (AutoRegressive Integrated Moving Average)
Объединяет AR, MA и интегрирование (взятие разностей для стационарности).
- Параметры: $(p, d, q)$.
- **SARIMA:** Добавляет сезонные компоненты.

## Специфика валидации

**Нельзя использовать обычную кросс-валидацию!** Она перемешает время, и вы будете предсказывать прошлое по будущему (Data Leakage).
- Используется **Time Series Split** (расширяющееся окно):
```
Fold 1: [Train: Jan] [Test: Feb]
Fold 2: [Train: Jan-Feb] [Test: Mar]
Fold 3: [Train: Jan-Mar] [Test: Apr]
```

## Каверзные вопросы

> [!question] Почему в рядах часто используют логарифмирование?
> Чтобы стабилизировать дисперсию. Если размах сезонных колебаний растет вместе с уровнем ряда (мультипликативная сезонность), логарифм превращает её в аддитивную (постоянный размах), с которой моделям проще работать.

## Типичные ошибки

- **Предсказание будущего по будущему:** Случайное включение признаков, которые станут известны только в момент t (например, среднее значение за весь месяц при прогнозе на завтра).
- **Игнорирование тренда:** Попытка обучить модель на нестационарном ряде без дифференцирования.
